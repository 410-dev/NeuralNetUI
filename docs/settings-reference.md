# 설정 레퍼런스

좌측 하단 프로필 → 설정에서 열리는 화면의 모든 항목입니다. 관리자 전용 탭은 표시해 두었습니다.

| 탭 | 접근 권한 |
| --- | --- |
| 일반 | 모두 |
| 모양 | 모두 |
| 연결 | 관리자 |
| MCP 연결 | 모두(플랜에서 사용 허용 필요) |
| 도구 | 관리자 |
| 실험실 | 관리자 |
| 모델 | 모두(일반 사용자는 자신의 alias) |
| 추론 | 모두(일반 사용자는 자신의 프리셋) |
| 사용자 | 관리자 |
| 플랜 | 관리자 |
| 데이터 관리 | 관리자 |
| 계정 | 모두 |

저장 버튼은 저장된 설정과 달라진 것이 있을 때만 활성화되고, 변경이 없으면 보조 버튼이 "취소" 대신 "닫기"로 바뀝니다.

## MCP 연결 탭

`연결`과 `도구` 사이에 표시됩니다. 계정이 소유한 MCP 연결을 추가·수정·삭제하고 플랜 등록 사용량을 확인합니다. 플랜에서 MCP를 끈 경우 기존 연결은 보존되고 삭제할 수 있지만 새 연결 등록, 수정, 테스트, 채팅 사용은 제한됩니다.

| 항목 | 기본값 | 범위·동작 |
| --- | --- | --- |
| MCP 이름 | — | 필수, 계정 안에서 고유, 최대 80자 |
| 설명 | 비어 있음 | 선택, 최대 500자 |
| 연결 URL | — | 사용자 정보가 없는 HTTP(S) Streamable HTTP 엔드포인트 |
| 인증 | 인증 없음 | OAuth, API Key, 인증 없음 |
| 인증 값 | 비어 있음 | OAuth 액세스 토큰 또는 API 키, 저장 후 다시 노출하지 않음 |
| 연결 사용 | 켜짐 | 끄면 정보는 유지되고 채팅 MCP 그룹에서 숨김 |
| 연결 테스트 | — | 도구 목록을 조회하고 확인된 도구 수를 표시 |
| 등록 개수 | — | 현재 플랜의 사용자별 최대 MCP 수까지 |

## 플랜 탭 (관리자)

각 플랜의 **MCP 사용 가능** 스위치와 **사용자당 최대 MCP 수**(1~100)를 설정합니다. MCP 사용을 끄면 해당 플랜 사용자의 기존 연결은 삭제하지 않고 비활성 접근 상태로 보존합니다. 활성 플랜의 등록 한도를 현재 사용자의 등록 수보다 낮추는 저장은 거부됩니다.
