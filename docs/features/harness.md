# 하네스와 컨텍스트

하네스는 모델 요청 바깥에서 대화를 관리하는 계층입니다. `설정 > 도구`에서 관리자가 설정합니다.

## 컨텍스트 사용량 표시

입력창의 도넛은 다음 요청이 소모할 것으로 **추정되는** 입력 토큰을 보여줍니다.

- 대화 이력, 작성 중인 초안, 첨부, 도구 컨텍스트를 모두 포함하며 입력·응답·추론으로 나누어 표시합니다.
- 구조적 추정치가 실제 토크나이저 청구량보다 낮게 나올 수 있어, 서버가 알려준 마지막 실측값을 바닥으로 삼고 그 이후 추가분을 더한 값을 씁니다.
- 압축이 일어나면 도넛은 **가장 최근 압축 지점부터** 세고, 요약이 덮는 이력 대신 요약을 계산에 넣습니다. 그래서 압축 효과가 도넛에 즉시 보입니다.
- 추론 재전송 토글을 바꾸면 즉시 반영됩니다.

컨텍스트 압축이나 롤링은 실제 상위 입력을 더 줄일 수 있으므로, 화면 문구는 항상 "추정"이라고 밝힙니다.

## 컨텍스트 모드

| 모드 | 동작 |
| --- | --- |
| **rolling** (기본) | 컨텍스트가 넘칠 때 가장 오래된 턴부터 잘라냅니다. 최신 턴 하나가 이미 한도를 넘으면 오류로 알립니다 |
| **compacting** | 임계값에 도달하면 이전 대화를 요약으로 대체합니다 |

### 압축

| 설정 | 기본값 | 범위 |
| --- | --- | --- |
| 압축 임계값 | 80% | 10 ~ 95% |
| 압축 모델 | 현재 대화의 기반 모델 | 비우면 기반 모델 |
| 압축 추론 강도 | off | — |
| 압축 프롬프트 | 내장 요약 지시 | 최대 32,000자 |

동작 방식:

- 압축 여부는 **추정치와 실측치 중 큰 값**으로 판단하며, 전송 직전과 스트리밍 도중 모두 확인합니다.
- 스트리밍 중에는 전달된 본문, 추론, 도구 인자를 SSE 이벤트 단위로 검사합니다.
- 요청 범위 AbortController가 추론만 중단하고 작업 자체는 취소하지 않습니다. 요약 동안 모델 상주 잠금을 반납했다가 재개할 때 다시 얻습니다.
- 도구 라운드 압축은 가장 최근 도구 요청·관찰을 유지하고, 텍스트 전용 요약에서는 이미지 페이로드를 제거합니다.
- 부분적으로 도착한 도구 호출은 **실행하지 않고** 데이터로만 요약합니다.
- 요약 요청은 직렬화된 이력이 너무 클 때 여러 조각으로 나누며, 각 조각에 이전 요약을 포함합니다.
- 브랜치 요약은 별도로 저장되고 SHA-256 지문으로 원본 이력을 검증한 뒤에만 재사용됩니다. 원본 메시지는 그대로 남습니다.
- 압축 단계는 대기 상태가 `compacting-context`로 바뀔 때 전사에 열리고, 완료 시 그 자리에서 요약·추론으로 채워집니다.

### 재개

압축 후 중단된 응답을 이어 쓰게 하는 설정입니다.

| 설정 | 기본값 | 범위 |
| --- | --- | --- |
| 재개 프롬프트 | 내장 지시 | 최대 32,000자 |
| 최대 재개 횟수 | 3 | 0 ~ 100 |

재개 프롬프트에는 두 자리 표시자를 한 번씩 쓸 수 있습니다.

| 표시자 | 치환 내용 |
| --- | --- |
| `%COMPRESSED%` | 압축 요약 |
| `%USER_PROMPT%` | 원래 사용자 요청 |

재개 횟수는 응답 하나 기준이며, 전송 전 압축은 세지 않습니다. 재개 재시도는 도구 라운드를 소모하지 않습니다. 원본 프롬프트·첨부와 이미 보인 부분 출력은 유지됩니다. 압축 후에도 입력이 불가능하면 전송 전에 실패로 처리합니다.

### 컨텍스트 초과 복구

상위 서버가 컨텍스트 초과를 알리면, 제한된 범위의 압축을 한 뒤에만 재시도합니다. 보정한 요청이 여전히 안전 상한(95%)을 넘으면, 보고된 토큰 수와 함께 지역화된 안정적인 오류를 사용자에게 보여주고 뷰포트·구간 단위 열람을 권합니다. 브라우저 스냅샷의 32,000자 상한과 전체 페이지 캡처 상한도 같은 문제를 예방하기 위한 장치입니다.

## 응답 길이

`maxOutputTokens`는 한 응답이 생성할 수 있는 토큰 상한입니다. `0`이면 남은 컨텍스트 창 전체를 씁니다(기본값). 범위는 0 ~ 1,000,000입니다.

## 제목 생성

| 설정 | 기본값 |
| --- | --- |
| 사용 여부 | 꺼짐 |
| 시점 | 응답 후 (`before` / `after`) |
| 모델 | 현재 대화의 기반 모델 |
| 추론 강도 | off |
| 프롬프트 | 내장 지시 |

켜면 첫 턴에서 대화 제목을 자동으로 만듭니다. 하네스 요청은 상주 잠금을 독립적으로 얻고 반납하므로, serial 정책에서도 교착이 생기지 않습니다.

## 도구와 파일 한도

| 항목 | 기본값 | 범위 |
| --- | --- | --- |
| 최대 도구 라운드 | 8 | 1 ~ 10,000 |
| 세션당 브라우저 탭 | 8 | 1 ~ 20 |
| 호출당 선택형 질문 | 3 | 1 ~ 10 |
| 메시지당 첨부 | 12 | 1 ~ 50 |
| 텍스트 다운로드 한도 | 1 MB | 0.0625 ~ 10 MB |
| 텍스트 글자 수 한도 | 24,000 | 1,000 ~ 1,000,000 |
| 이미지 다운로드 한도 | 10 MB | 1 ~ 50 MB |
| 이미지 업로드 한도 | 20 MB | 1 ~ 50 MB |
| PDF 용량 한도 | 25 MB | 1 ~ 100 MB |
| PDF 페이지 한도 | 100 | 1 ~ 500 |
| PDF 추출 글자 수 | 100,000 | 1,000 ~ 1,000,000 |
| PDF 비전 페이지 수 | 6 | 0 ~ 20 |
| PDF 처리 제한 시간 | 30초 | 5 ~ 120초 |
| 임시 파일 보관 시간 | 60분 | 5 ~ 1,440분 |
| 미첨부 업로드 보관 시간 | 24시간 | 1 ~ 168시간 |

도구 호출은 순차 실행이므로 병렬 호출 한도는 없습니다.

## 호스트 신뢰

호스트 컴퓨터 도구의 승인 정책도 하네스 설정에 있습니다. 신뢰 모드, 27행 권한 매트릭스, 명령 위험도 평가용 모델·강도·프롬프트를 여기서 정하며, Superadmin만 읽고 쓸 수 있습니다. 자세한 내용은 [도구](tools.md#호스트-컴퓨터-실험-기능)를 참고하세요.

## 작업 수명

- 삭제된 대화와 사용자의 채팅 작업은 즉시 폐기됩니다.
- 백그라운드 저장은 SQLite 트랜잭션 안에서 작업 소유권과 대화 존재를 검증합니다.
- 종료된 작업은 전체 이력을 해제하고 60초 뒤 만료되며, 최대 64개까지만 보관됩니다.
