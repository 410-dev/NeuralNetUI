# 모양과 언어

`설정 > 모양`의 선택은 모두 **표시 전용**입니다. 모델에 보내는 입력이나 저장된 대화를 바꾸지 않으며, 계정별로 저장됩니다.

## 언어

`설정 > 일반`에서 전체 인터페이스 언어를 영어와 한국어 중에 고릅니다. 저장하면 다음 접속에도 유지됩니다.

## 액센트 색

| 항목 | 값 |
| --- | --- |
| 팔레트 | blue, violet, teal, amber, rose, graphite, custom |
| 커스텀 | `#RRGGBB` 6자리 16진수 |

설정 패널이 열려 있는 동안 선택한 색이 즉시 미리보기로 적용됩니다. 액센트는 CSS 변수 `--accent-rgb` / `--accent-bright-rgb`로 전달되며, 스타일시트에 색상 값을 직접 박아 넣지 않는 것이 이 프로젝트의 규칙입니다.

로그인 화면의 액센트는 관리자가 정하는 **워크스페이스 단위** 설정입니다.

## 스트리밍 표현

| 설정 | 값 | 의미 |
| --- | --- | --- |
| 표시 방식 | `instant` / `fade` | 새 텍스트를 즉시 보이거나 서서히 드러냅니다 |
| 속도 | `immediate` / `chunked` | 도착 즉시 표시하거나 일정 단위로 나누어 표시합니다 |
| 조각 크기 | 1 ~ 24 (기본 3) | `chunked`일 때 한 번에 내보낼 글자 수 |

## 진행률 표시

LM Studio가 제공하는 모델 로드·프롬프트 처리 진행률의 표시 방식을 고릅니다.

| 값 | 표시 |
| --- | --- |
| `text` | 문장으로만 |
| `percent` | 퍼센트 숫자 |
| `donut` | 도넛 그래프 |
| `both` | 도넛과 숫자 함께 (기본) |

## 인사말

메인 화면의 인사말은 하루를 일곱 시간대로 나눠 표시합니다.

| 키 | 시간대 |
| --- | --- |
| `earlyDawn` | 새벽 이른 시간 |
| `morning` | 아침 |
| `midday` | 한낮 |
| `afternoon` | 오후 |
| `evening` | 저녁 |
| `night` | 밤 |
| `lateNight` | 늦은 밤 |

- 언어별·시간대별로 최대 5줄(각 200자)까지 직접 작성할 수 있습니다.
- 표시할 때 무작위로 고르되, 계정·언어·시간대별로 직전에 보인 문장은 제외합니다. 타이핑한다고 문구가 다시 뽑히지는 않습니다.
- 비워두면 기본 문구로 되돌아갑니다.
- `{name}`은 사용자의 이름(첫 단어)으로 치환됩니다.

## 추론 설명

채팅 선택기에 각 추론 강도의 설명을 함께 보일지 정하고, 강도별 문구(각 200자)를 덮어쓸 수 있습니다. 비우면 현재 언어의 기본 문구를 사용하므로 언어를 바꿔도 읽을 수 있는 설명이 유지됩니다.

## 표시 옵션

| 옵션 | 위치 | 설명 |
| --- | --- | --- |
| 모델 identifier 표시 | 일반 | 응답에 모델 ID를 함께 보입니다 |
| 모델 가중치 표시 (관리자) | 모양 | 플랜 가중치가 1이 아닌 모델의 선택 메뉴 오른쪽에 `x1.75` 딱지를 표시하고, 마우스를 올리면 "토큰을 1.75배 더 빨리 소모합니다"를 보여줍니다. 기준은 관리자 본인의 플랜이며 일반 사용자에게는 가중치가 전달되지 않습니다 |
| 취소선 렌더링 | 일반 | 단일·이중 물결표 취소선을 렌더링합니다. 끄면 원본 물결표를 그대로 보존합니다 |
| 추론 내보내기 | 일반 | 대화 내보내기에 추론 내용을 포함합니다 |
| 이전 추론 전달 | 입력창 Reasoning 메뉴 | 직전 응답의 `reasoning_content`를 다음 요청에 포함합니다 |

## 레이아웃

- 데스크톱 사이드바 접기 상태는 브라우저 로컬 저장소에 유지됩니다.
- 설정 탭은 좁은 화면에서 가로로 스크롤됩니다.
- 입력창은 한 줄 알약 모양이었다가, 작성 중인 글이 컨트롤 옆 공간을 넘거나 큐·첨부·업로드가 한 줄을 차지하면 둥근 사각형으로 늘어납니다. 컨트롤 옆 공간이 150px 미만이면 처음부터 세로로 쌓인 배치를 씁니다.
