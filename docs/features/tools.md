# 도구

입력창의 `+` 메뉴에서 도구를 개별로 켭니다. **활성화된 도구만** OpenAI 호환 `tools` 정의로 모델에 전달되고, 모델이 호출하면 서버가 결과를 실행해 같은 요청 흐름 안에서 모델에 돌려줍니다.

메뉴는 네 기본 그룹으로 접히며, 등록된 MCP가 있으면 **상호 작용 바로 아래에 MCP 그룹이 추가**됩니다. 기본 도구도 MCP 연결과 같은 모양의 행으로 표시되며, 행마다 폴드를 펼치면 그 도구가 모델에 제공하는 함수와 옵션(예: 저장소 읽기·쓰기)을 볼 수 있습니다. 기본 도구와 MCP 연결의 켜고 끈 상태와 옵션은 계정에 저장되고, MCP 연결의 함수별 선택은 현재 대화에만 적용됩니다. 구조는 [도구 레지스트리 설계](../design/tool-registry.md)에 있습니다.

| 그룹 | 도구 |
| --- | --- |
| 인터넷 | 인터넷 검색, 페이지 방문, 브라우저, 유튜브 |
| 주변 인식 | 현재 시간, 현재 위치 |
| 에이전트 | 저장소 접근, 코드 실행 |
| 상호 작용 | 다중 선택, 아티팩트 |
| MCP (등록된 연결이 있을 때) | 사용자가 등록한 MCP 연결과 연결별 도구 |

## 도구 요약

| 도구 | 함수 이름 | 필요한 조건 |
| --- | --- | --- |
| 인터넷 검색 | `internet_search` | Python `ddgs` |
| 페이지 방문 | `visit_page` | — |
| 브라우저 | `browser_*` (Obscura MCP 도구), `browser_download_file` | 하네스에 Obscura 바이너리 설치 |
| 유튜브 | `get_youtube_subtitles`, `list_youtube_subtitles`, `download_youtube_video` | 하네스에 yt-dlp 설치 |
| 저장소 접근 | `storage_access` | — |
| 코드 실행 | `run_javascript`, `run_python` | 채팅을 연 브라우저. Python은 jsDelivr 접속 |
| 현재 시간 | `get_current_time` | — |
| 현재 위치 | `get_current_location` | 브라우저 위치 권한 |
| 다중 선택 | `ask_multiple_choice` | — |
| 아티팩트 | `create_artifact` | — |
| MCP 연결 | `mcp_<연결 식별자>_<도구 이름>` | 플랜에서 MCP 허용 + 활성 연결 |

## 인터넷 검색

Python `ddgs` 패키지로 DuckDuckGo를 검색해 제목, URL, 스니펫을 돌려줍니다. 한 번에 1~10건을 요청할 수 있습니다. DDGS 하위 프로세스의 JSON 입출력은 명시적으로 UTF-8이므로 Windows 코드 페이지 때문에 응답이 깨지지 않습니다.

## 페이지 방문

공개 HTTP(S) 주소의 제목과 본문을 읽습니다.

| 응답 종류 | 처리 |
| --- | --- |
| HTML, JSON, XML, CSV 등 텍스트 | 설정된 글자 수 한도까지 디코딩해 전달 |
| 안전한 래스터 이미지 | 비전 입력으로 전달 |
| PDF | 임시 파일로 처리한 뒤 즉시 삭제 |
| 압축 파일, 실행 파일, 기타 바이너리 | 열지 않음 |

요청은 브라우저 호환 User-Agent에 NeuralChat 제품 토큰을 함께 담습니다. localhost와 사설 IP 대역은 차단되며, 이 검사는 DNS 해석 결과에도 적용됩니다.

## 브라우저

[Obscura](https://github.com/h4ckf0r0day/obscura) 헤드리스 브라우저입니다. 화면은 보이지 않고, 모델이 Obscura MCP 서버의 도구(`browser_navigate`, `browser_snapshot`, `browser_click`, `browser_fill`, `browser_markdown`, `browser_screenshot`, `browser_pdf` 등)를 그대로 씁니다. 관리자가 `설정 > 도구 > 브라우저 (Obscura)`에 `obscura`와 `obscura-worker` 두 실행 파일을 넣어야 메뉴에 나타납니다.

- **세션 프록시**: Obscura MCP 서버는 프로세스 하나가 브라우저 세션 하나라서 여러 사용자를 전제하지 않습니다. 앞단의 작은 프록시(`lib/obscura.ts`)가 대화마다 `obscura mcp` 프로세스를 따로 띄우고(계정·대화별 프로필 폴더로 쿠키와 localStorage 격리), 한 세션의 호출은 순서대로 하나씩 처리합니다.
- **메모리 회수**: 정해진 시간(기본 10분) 동안 쓰지 않은 세션은 프로세스를 종료해 메모리를 돌려줍니다. 프로필은 디스크에 남아 다음 호출에서 새 프로세스가 같은 쿠키로 이어 갑니다. 동시 세션 수(기본 8)가 가득 차면 가장 오래 쉰 세션부터 종료하고, 모두 작업 중이면 잠시 뒤 다시 시도하라고 알립니다. 대화를 지우면 프로필도 지웁니다.
- **render / stealth**: 렌더링을 끄면 `browser_screenshot`·`browser_pdf`를 모델에 제공하지 않습니다. 스텔스를 켜면 `--stealth`로 실행합니다(일관된 지문과 추적기 차단, stealth 빌드는 TLS 지문 위장까지). 기본값은 둘 다 켜짐입니다.
- **파일 다운로드**: `browser_download_file`은 대화의 프로필 사본(쿠키 포함)으로 `obscura fetch --dump original`을 실행해 원본 바이트를 받고 개인 저장소에 넣습니다. 받는 도중 남은 저장 공간을 넘으면 즉시 멈추고 아무것도 남기지 않습니다. 파일 확장자의 주소가 HTML(봇 확인·로그인 페이지)을 돌려주면 저장하지 않고 이유를 알립니다. `browser_pdf` 결과도 개인 저장소에 저장됩니다.
- Obscura 자체의 SSRF 보호로 localhost와 사설망 주소에는 접근하지 않습니다.

## 유튜브

하네스에 설치한 [yt-dlp](https://github.com/yt-dlp/yt-dlp)로 유튜브 자막을 텍스트로 읽고, 요청하면 영상을 개인 저장소에 내려받습니다. 예전 `mcp-extensions/youtube-subtitle` MCP 서버를 내장 도구로 옮긴 것입니다.

| 함수 | 하는 일 |
| --- | --- |
| `get_youtube_subtitles` | 제목·채널·길이·업로드 날짜와 자막 전문. 긴 자막은 `offset`으로 이어 받음 |
| `list_youtube_subtitles` | 업로드 자막과 자동 자막 언어 |
| `download_youtube_video` | 영상을 받아 개인 저장소에 저장(`max_height`로 해상도 상한) |

- 자막은 영상 원어 업로드 자막 → 선호 언어 업로드 자막 → 그 밖의 업로드 자막 → 원어 자동 자막 → 선호 언어 자동 자막(기계 번역 표시) 순으로 고릅니다.
- 다운로드 한도는 개인 저장소의 남은 공간과 하네스의 영상 최대 크기 중 작은 값입니다. 예상 크기가 넘으면 시작하지 않고, 받는 중 넘으면 멈추고 지웁니다. ffmpeg가 있으면 최고 화질 영상과 오디오를 합치고, 없으면 가장 좋은 단일 파일을 받습니다.
- 유튜브 플레이어 스크립트는 앱의 Node.js로 풀어 전체 화질 목록을 받습니다(`--js-runtimes node`).
- **쿠키(서버 전체)**: 로그인해야 보이는 영상이나 "봇이 아님을 확인" 오류에는 관리자가 `설정 > 하네스 설정 > 유튜브 (yt-dlp) > 쿠키`에 Netscape 형식 cookies.txt를 올립니다(yt-dlp가 설치되어 있을 때 표시). 서버 전체가 쓰는 파일(0600)로 보관되고 다시 내려받을 수 없으며, 실행마다 임시 사본을 yt-dlp에 넘깁니다. 이전 버전에서 계정별로 올린 쿠키는 서버 전체 쿠키가 없을 때만 그 계정에 쓰입니다.

## 코드 실행

모델이 쓴 JavaScript나 Python을 **서버가 아닌 사용자의 브라우저**에서 실행합니다. **에이전트** 그룹에 있고 기본으로 꺼져 있습니다. 행의 폴드에서 언어별로 켜고 끌 수 있고, 실행 제한 시간(5~120초, 기본 30초)을 정합니다.

| 함수 | 실행 환경 | 결과 |
| --- | --- | --- |
| `run_javascript` | 격리된 Web Worker | `console.log` 등 출력, 최상위 `return` 값 |
| `run_python` | Pyodide (WebAssembly Python) | `print` 출력, 마지막 식의 `repr` |

- 서버는 코드를 실행하지 않습니다. 실행 요청을 도구 이벤트에 기록하고, 채팅을 보고 있는 브라우저가 실행한 결과를 받아 길이를 제한한 뒤 모델에 전달합니다. 결과를 보내 줄 브라우저 탭이 열려 있어야 합니다.
- 코드는 화면에 보이지 않는 `sandbox="allow-scripts"` iframe 안의 Worker에서 돕니다. iframe은 앱과 다른 불투명 출처라 앱의 쿠키·저장소·화면에 접근할 수 없고, CSP가 네트워크를 막습니다. JavaScript는 네트워크가 완전히 막혀 있고, Python은 패키지를 받기 위한 jsDelivr만 허용됩니다.
- 제한 시간을 넘기면 Worker를 종료합니다. 무한 루프가 있어도 화면은 멈추지 않습니다. Python 로딩 시간은 제한 시간에 포함하지 않습니다.
- 호출마다 새 상태에서 시작합니다. JavaScript는 매번 새 Worker를 쓰고, Python은 탭 안에서 인터프리터만 유지하고 변수는 매번 새로 만듭니다.
- Python은 탭에서 처음 실행할 때 jsDelivr에서 Pyodide 0.29.5(약 11MB)를 받습니다. 이후는 브라우저 캐시를 씁니다. `import numpy`처럼 Pyodide에 포함된 패키지는 import 문을 보고 자동으로 받습니다. 외부 인터넷이 막힌 환경에서는 Python을 쓸 수 없고 JavaScript만 동작합니다.
- 출력, 오류, 반환값은 각각 20,000자까지 모델에 전달됩니다. 그림이나 화면 출력은 지원하지 않습니다.

## 저장소 접근

저장소 접근은 **에이전트** 그룹에 있습니다. 행의 토글 왼쪽 폴드를 펼치면 **읽기**와 **쓰기**를 따로 켤 수 있습니다. 읽기는 개인 저장소 검색과 모델 컨텍스트 불러오기를 허용합니다. 쓰기는 텍스트 기반 파일을 새로 만들거나 URL 파일을 저장할 수 있으며, 알약형 숫자 필드의 1~20개 대화당 한도를 넘으면 서버가 거부합니다. 쓰기는 기본적으로 꺼져 있습니다.

모델이 **현재 사용자 소유**의 개인 저장소를 검색하고 읽게 합니다. 다른 사용자의 파일과 삭제된 파일에는 접근할 수 없습니다.

### URL 파일 저장 (`save_url`)

쓰기가 켜져 있으면 모델이 HTTP(S) URL을 넘겨 파일을 개인 저장소로 내려받을 수 있습니다. 예를 들어 이미지 생성 MCP가 `https://…/files/<id>` 같은 URL을 반환하면, 모델이 `save_url`로 이미지를 저장하고 결과의 Markdown(`![이름](/api/uploads/<id>)`)을 답변에 넣어 채팅 화면에 이미지를 바로 표시합니다. 이미지가 아닌 파일은 다운로드 링크 Markdown을 돌려받습니다.

- 쓰기와 같은 대화당 파일 한도에 포함됩니다.
- 파일명은 `name` 인자 → `Content-Disposition` → URL 경로 마지막 부분 순으로 정해지고, 확장자 없는 이미지는 실제 시그니처에 맞는 `.png`/`.jpg`/`.webp`/`.gif`가 붙습니다.
- 파일은 임시 디렉터리로 스트리밍된 뒤 할당량 검사를 거쳐 보존 파일로 등록되며, 크기 한도는 하네스의 이미지·PDF·텍스트 다운로드 한도 중 가장 큰 값입니다.
- 리디렉션은 최대 4회이며 매 단계 주소를 다시 검사합니다. 링크 로컬·예약 주소는 항상 거부하고, 루프백·사설망 주소는 MCP 내부망 연결과 마찬가지로 관리자 계정에서만 허용합니다. 따라서 실제 파일 호스트가 LAN이나 Tailscale 안에 있어도 관리자 계정은 저장할 수 있습니다.

| 액션 | 인자 | 결과 |
| --- | --- | --- |
| `search` | `query`, `sort`, `limit`(1~20) | 파일 ID, 이름, MIME 타입, 크기, 생성 시각 |
| `read` | `file_id` 또는 `query` | 종류에 맞는 모델 입력 |

읽기 결과는 종류별로 다릅니다. 이미지는 비전 입력으로, PDF는 추출 텍스트와 필요 시 렌더링된 페이지로, 안전한 텍스트 파일은 디코딩된 텍스트로 전달됩니다. 파일 이름이 모호하면 후보 목록을 돌려주고 모델이 다시 고르게 합니다.

사용자가 첨부 없이 저장된 파일 이름만 언급했을 때 유용합니다.

## 현재 시간과 현재 위치

- `get_current_time` — 사용자의 현재 날짜·시각을 초와 IANA 시간대까지 포함해 돌려줍니다.
- `get_current_location` — 브라우저에 위치를 요청한 뒤 좌표와 역지오코딩 결과(국가, 지역, 도시, 세부 행정구역)를 돌려줍니다. 브라우저 위치 권한이 필요합니다.

## 다중 선택 질문

모델이 선택형 질문으로 사용자의 의도를 좁힐 수 있습니다. 질문은 기술적인 도구 폴딩 대신 **입력창 위의 전용 카드**에 한 번에 하나씩 표시됩니다.

| 질문 유형 | 의미 |
| --- | --- |
| `single_select` | 정확히 하나 선택 |
| `multi_select` | 여러 개 선택 |
| `rank_priorities` | 우선순위 정렬 |

- 한 호출에 담을 수 있는 질문 수는 `설정 > 도구`에서 정합니다(기본 3, 최대 10). 선택지는 질문당 2~4개입니다.
- 답변하면 다음 질문으로 슬라이드 전환되고, 제출한 질문·답변 쌍은 사용자 메시지 형태로 대화에 남은 뒤 모델 응답이 이어집니다.
- 직접 입력란으로 목록에 없는 답을 쓸 수도 있습니다.
- 질문 대기 중에도 생성 중단 버튼이 동작합니다.

## MCP 연결

`설정 > MCP 연결`에서 계정별 원격 MCP 서버를 여러 개 등록합니다. 등록 창에는 이름, 선택 설명, Streamable HTTP 연결 URL, 인증 방식, 연결 사용 여부가 있습니다. 인증은 OAuth 액세스 토큰, API Key, 인증 없음 중 하나이며 OAuth와 API Key 값은 현재 Bearer 토큰으로 전송됩니다. 저장된 인증 값은 설정 응답이나 화면으로 다시 보내지 않습니다.

- 연결 테스트는 서버의 도구 목록을 조회해 접근 가능 여부와 도구 수를 확인합니다.
- 연결 행의 톱니 버튼에서 서버 도구 목록, 설명, 입력 스키마를 확인합니다. 각 도구 정책은 **차단 / 항상 묻기 / 세션마다 묻기 / 항상 허용** 중 하나입니다. 기본값은 세션마다 묻기입니다.
- 차단된 도구는 모델에 전달되지 않습니다. 확인 정책은 실제 실행 전에 사용자 승인을 받고, 세션 승인은 같은 대화에서 재사용됩니다.
- 채팅 메뉴에서는 MCP 연결 단위 스위치와 연결별 폴드가 함께 표시됩니다. 폴드 안의 개별 토글은 현재 대화에서 모델에 전달할 도구만 조정하며, 설정에서 차단한 도구는 켤 수 없습니다. 도구 이름은 연결별 네임스페이스로 분리됩니다.
- 실행 전 승인이 필요한 도구는 승인 카드에 연결·도구 이름, 도구 설명과 핵심 요청 인자로 만든 작업 목적, 전체 인자를 함께 표시합니다. 민감정보로 보이는 인자는 목적 요약에서 제외합니다.
- 텍스트, 이미지, 텍스트 리소스, 구조화 결과를 모델의 후속 입력으로 돌려줍니다. 결과는 모델에 넘기기 전에 줄입니다.
  - 구조화 결과(`structuredContent`)가 있으면 같은 JSON을 담은 텍스트 부분은 보내지 않습니다(MCP 규격상 서버가 둘 다 보냄).
  - JSON은 들여쓰기·이스케이프(`\u003c` 등) 없이 다시 직렬화합니다.
  - 메일 본문: 일반 텍스트 본문(`plaintextBody` 등)이 있으면 HTML 본문(`htmlBody` 등)을 빼고, HTML만 있으면 텍스트로 바꿔 `htmlBodyAsText`로 넣습니다. Gmail `get_thread`는 형식을 지정하지 않아도 HTML 본문을 함께 돌려줍니다.
  - base64 같은 2,000자 이상의 인코딩 데이터와 `data:` URL은 길이만 알리는 메모로 바꿉니다.
  - 호출 하나의 텍스트는 합쳐서 50,000자까지 보내고, 넘으면 자른 뒤 범위를 좁혀 다시 요청하라고 알립니다.
  - 안 읽은 메일 8통을 연 실제 대화에서 결과가 55만 자에서 4.6만 자로 줄었습니다.
- 연결의 **도구 실행 타임아웃은 침묵 시간 제한**입니다. 서버가 MCP 진행 알림(`notifications/progress`)을 보낼 때마다 다시 시작하므로, 진행을 알리는 도구는 타임아웃보다 오래 걸려도 끊기지 않습니다. 진행 상황은 도구 활동에 표시됩니다. 결과도 진행 알림도 없이 타임아웃이 지나면 중단합니다.
- **저장소로 파일 받기**: 결과의 `resource_link`에 `_meta["nnui/saveToStorage"] = true`와 상대 경로 `_meta["nnui/path"]`가 있으면, NeuralNetUI가 그 파일을 MCP 연결과 같은 호스트에서 같은 인증으로 받아 호출한 사용자의 개인 저장소에 저장합니다. 할당량을 먼저 예약하고, 별도 영역에 받은 뒤 크기와 `_meta.sha256`이 맞을 때만 등록합니다. 받는 동안에는 전체 시간 제한이 없고 데이터가 1분(또는 연결 타임아웃 중 긴 쪽) 동안 오지 않을 때만 실패합니다. 실패하면 예약과 받던 데이터를 지우므로 저장소에 깨진 파일이 남지 않습니다. 성공하면 같은 경로로 `DELETE`를 보내 서버의 사본을 지우고, 모델에게는 저장된 파일 이름·크기·다운로드 링크를 전달합니다.
- 플랜이 MCP를 허용할 때만 등록·테스트·호출할 수 있으며, 사용자별 최대 등록 수는 플랜 설정을 따릅니다. 플랜에서 사용을 끄면 기존 등록 정보는 보존되지만 채팅 도구에서는 숨겨집니다.
- 서버 응답이 실패하면 상위 HTTP 상태와 확인할 점(경로 `/mcp`, 인증 키, 프록시의 http/https 설정)을 담은 메시지를 보여 줍니다. NeuralNetUI 자신은 이때 400으로 응답하므로, NeuralNetUI 앞의 Cloudflare Tunnel 같은 프록시가 응답을 오류 페이지로 바꾸지 않습니다.
- 일반 계정은 공개 주소만 연결할 수 있습니다. 관리자 계정은 사설망 주소도 쓸 수 있지만 링크 로컬·예약 주소와 HTTP 리디렉션은 모든 계정에서 차단합니다.

## 아티팩트

모델이 `create_artifact`로 생성한 결과는 기술적인 도구 로그와 분리된 카드로 표시됩니다. 카드의 **펼치기**는 모달 없이 그 자리에서 가로:세로 2:3 비율의 미리보기를 표시하고, **접기**로 닫습니다. 왼쪽 **열기**는 기존 전용 뷰어를 엽니다. 뷰어의 다운로드 옆 **미리보기 / 코드** 세그먼트로 HTML·CSV·JSON·XML·Markdown 모두 렌더링 결과와 원본을 전환합니다.

| 형식 | 표시 방식 |
| --- | --- |
| HTML | 출처가 격리된 `sandbox` 웹뷰에서 렌더링. 플랜에서 허용하면 JavaScript와 아티팩트 전용 Local Storage 실행 |
| CSV | 고정 헤더와 스크롤을 지원하는 표 |
| JSON, XML | 중첩 항목을 접고 펼칠 수 있는 트리 |
| Markdown | GFM 문서 렌더링 |

HTML은 실행 결과만 보여 줍니다. CSV, JSON, XML, Markdown은 편집 모드에서 원본과 렌더링 결과를 나란히 확인할 수 있고, 저장한 변경은 현재 대화의 도구 결과에 반영됩니다. 모든 형식은 원본 파일로 다운로드할 수 있으며 도구 입력은 UTF-8 기준 1MB로 제한됩니다.

HTML 아티팩트의 Local Storage는 계정과 아티팩트별로 브라우저에 분리해 저장합니다. 앱 자체의 Local Storage와 공유하지 않으며, 아티팩트를 다시 열거나 페이지를 새로고침해도 값이 유지됩니다. 브라우저 저장소가 차단되거나 가득 차면 현재 미리보기의 메모리에서는 동작하지만 영구 저장은 실패할 수 있습니다. 플랜 정책을 끄면 스크립트가 실행되지 않아 Local Storage API도 사용할 수 없습니다.

## 실행 규칙과 한도

- 도구 호출은 **순차 실행**입니다. 병렬 호출 한도가 없는 이유입니다.
- 실행 중 **생성 중단**을 누르면 현재 도구에 취소 신호를 전달합니다. 장시간 호스트 셸 명령은 자식 프로세스 트리까지 종료하고, 웹·저장소·파일 처리 작업도 다음 취소 지점에서 중단됩니다.
- 한 응답의 최대 도구 라운드는 `설정 > 도구`에서 정합니다(기본 8, 최대 10,000).
- 저장된 도구 호출·결과 쌍은 후속 요청에서 복원되어 모델이 맥락을 잃지 않습니다.
- 도구가 만든 이미지 중 보존 대상은 미첨부 업로드 정리에서 제외됩니다.
- 관리자가 입력한 모든 한도 값은 서버의 안전 범위 안에서 검증됩니다. 전체 목록은 [설정 레퍼런스](../settings-reference.md#도구-탭-관리자)에 있습니다.


## MCP 연결의 OAuth 로그인

MCP 연결의 인증을 **OAuth**로 두고 **클라이언트 ID**를 넣으면 NeuralNetUI가 직접 로그인합니다(인증 코드 + PKCE). 클라이언트 ID가 없으면 예전처럼 붙여 넣은 액세스 토큰을 Bearer로 보냅니다.

1. 연결 URL, 클라이언트 ID·시크릿을 넣습니다. Google Gmail(`https://gmailmcp.googleapis.com/mcp/v1`)·Calendar(`https://calendarmcp.googleapis.com/mcp/v1`) MCP 주소를 넣으면 인증·토큰 주소와 권한 범위가 자동으로 채워집니다.
2. 창에 표시되는 **리디렉션 URI**(`https://<이 서버>/api/mcp-connections/oauth/callback`)를 OAuth 클라이언트에 등록합니다.
3. **저장하고 로그인**을 누르면 새 창에서 제공자 로그인이 열리고, 허용하면 설정 창에 "로그인됨"이 표시됩니다.

- 액세스 토큰은 만료 90초 전에 리프레시 토큰으로 자동 갱신합니다(같은 연결은 한 번에 하나씩). Google에는 `access_type=offline`, `prompt=consent`를 붙여 리프레시 토큰을 받습니다.
- 클라이언트 시크릿, 리프레시 토큰, 액세스 토큰은 서버에만 저장되고(마이그레이션 34, `mcp_connections.oauth`) 브라우저에는 로그인 여부만 전달됩니다.
- 클라이언트 ID, 주소, 권한 범위, 연결 URL을 바꾸면 기존 로그인은 지워지고 다시 로그인해야 합니다.
- 로그인 콜백은 다른 사이트에서 돌아오는 요청이라 세션 쿠키(SameSite=Strict)가 실리지 않으므로, 로그인을 시작할 때 만든 일회용 state(10분, 계정·연결에 묶임)로 확인합니다.

## MCP 도구 정의 전달 방식

MCP 연결마다 도구 정의를 모델에 어떻게 보낼지 고릅니다(마이그레이션 35, `mcp_connections.tool_definitions`). 가상 컴퓨터는 항상 전체입니다.

| 방식 | 동작 |
|---|---|
| 길이 제한 (기본) | 도구 설명은 1,000자, 입력 항목 설명은 300자에서 자릅니다. 형식·필수 항목·선택지(enum)는 그대로 |
| 필요할 때만 | 도구 이름과 첫 문장(160자 이내)만 보내고 입력 형식은 비워 둡니다. 연결마다 `mcp_<id>_get_tool_details`가 추가되어, 모델이 쓰려는 도구의 전체 설명과 입력 형식을 도구 목록에 올립니다(그 응답의 다음 요청부터, 그리고 이 대화의 이후 응답에서도 계속). 그래서 컨텍스트 압축이 앞의 도구 결과를 버려도 정의는 남습니다. 이 대화에서 정의를 받아 본 적 없는 도구를 부르면 실행하지 않고 정의를 도구 목록에 올리며, 모델은 그것을 보고 다시 부릅니다. Google Gmail·Calendar MCP 주소는 이 방식으로 시작합니다 |
| 전체 | 서버가 보낸 그대로 |

Google Gmail·Calendar 도구 39개는 전체로 보내면 약 105KB(도구 정의만으로 요청마다 수만 토큰)인데, 그중 81%가 입력 형식이고 절반 이상이 입력 항목 설명입니다.

## MCP 승인 요청 (form elicitation)

Google Workspace MCP 서버(`*.googleapis.com`)는 상태 없는 MCP 방식(프로토콜 `2026-07-28`)으로 부릅니다. 세션 없이 요청마다 `MCP-Protocol-Version`, `Mcp-Method`, (`tools/call`이면) `Mcp-Name` 헤더와 `params._meta`의 `io.modelcontextprotocol/protocolVersion`·`clientInfo`·`clientCapabilities`(`{"elicitation":{"form":{}}}`)를 보냅니다(`lib/mcp-stateless.ts`).

- 승인을 지원한다고 알리지 않으면 Gmail은 메일을 `omittedContent: DATA_PROTECTION_POLICY`로 빼고 돌려줍니다.
- 서버가 `resultType: "input_required"`와 `inputRequests`를 돌려주면 입력창 위에 승인 카드가 뜹니다. 선택지 하나짜리 질문은 선택지마다 버튼으로, 나머지는 작은 양식으로 보여 줍니다. 고른 답은 `params.requestState`·`params.inputResponses`에 담아 같은 호출을 다시 보냅니다(최대 4번). 답은 서버로만 가고 모델에게는 가지 않습니다.
- 개인 에이전트는 응답할 사람이 없어 `decline`으로 답합니다. 일반 채팅에서 "이 도구 항상 허용"을 골라 두면 서버가 기억해 이후로는 묻지 않습니다.
