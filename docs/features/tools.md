# 도구

입력창의 `+` 메뉴에서 도구를 개별로 켭니다. **활성화된 도구만** OpenAI 호환 `tools` 정의로 모델에 전달되고, 모델이 호출하면 서버가 결과를 실행해 같은 요청 흐름 안에서 모델에 돌려줍니다.

메뉴는 네 기본 그룹으로 접히며, 등록된 MCP가 있으면 **상호 작용 바로 아래에 MCP 그룹이 추가**됩니다. 기본 도구와 MCP 연결의 켜고 끈 상태는 계정에 저장됩니다. 저장소 접근과 MCP 연결 행은 별도 폴드를 제공해 현재 대화의 세부 권한을 조정합니다.

| 그룹 | 도구 |
| --- | --- |
| 인터넷 | 인터넷 검색, 페이지 방문, 브라우저 |
| 주변 인식 | 현재 시간, 현재 위치 |
| 에이전트 | 저장소 접근, 호스트 컴퓨터 |
| 상호 작용 | 다중 선택, 아티팩트 |
| MCP (등록된 연결이 있을 때) | 사용자가 등록한 MCP 연결과 연결별 도구 |

## 도구 요약

| 도구 | 함수 이름 | 필요한 조건 |
| --- | --- | --- |
| 인터넷 검색 | `internet_search` | Python `ddgs` |
| 페이지 방문 | `visit_page` | — |
| 브라우저 | `browser` | 관리자가 실험실에서 활성화 + Chromium |
| 저장소 접근 | `storage_access` | — |
| 현재 시간 | `get_current_time` | — |
| 현재 위치 | `get_current_location` | 브라우저 위치 권한 |
| 다중 선택 | `ask_multiple_choice` | — |
| 아티팩트 | `create_artifact` | — |
| MCP 연결 | `mcp_<연결 식별자>_<도구 이름>` | 플랜에서 MCP 허용 + 활성 연결 |
| 호스트 컴퓨터 | `host_computer` | Superadmin + 실험실 활성화 + 비컨테이너 호스트 |

## 인터넷 검색

Python `ddgs` 패키지로 DuckDuckGo를 검색해 제목, URL, 스니펫을 돌려줍니다. 한 번에 1~10건을 요청할 수 있습니다. DDGS 하위 프로세스의 JSON 입출력은 명시적으로 UTF-8이므로 Windows 코드 페이지 때문에 응답이 깨지지 않습니다.

## 페이지 방문

공개 HTTP(S) 주소의 제목과 본문을 읽습니다.

| 응답 종류 | 처리 |
| --- | --- |
| HTML, JSON, XML, CSV 등 텍스트 | 설정된 글자 수 한도까지 디코딩해 전달 |
| 안전한 래스터 이미지 | 비전 입력으로 전달 |
| PDF | 임시 파일로 처리한 뒤 즉시 삭제 |
| 압축 파일, 실행 파일, 기타 바이너리 | 열지 않음 |

요청은 브라우저 호환 User-Agent에 NeuralChat 제품 토큰을 함께 담습니다. localhost와 사설 IP 대역은 차단되며, 이 검사는 DNS 해석 결과에도 적용됩니다.

## 브라우저

`visit_page`가 렌더링하지 못하는 페이지를 위해 **실제 Chromium에서 JavaScript를 실행**합니다. 관리자가 `설정 > 실험실`에서 켜야 사용할 수 있고, 클라이언트가 무엇을 보내든 서버가 비활성 상태를 강제합니다.

### 모델이 쓸 수 있는 동작

| 분류 | 액션 |
| --- | --- |
| 세션 | `open`, `close` |
| 탐색·조작 | `inspect`, `click`, `type`, `select`, `press`, `scroll`, `wait`, `screenshot` |
| 탭 | `list_tabs`, `new_tab`, `switch_tab`, `close_tab`, `set_tab_metadata` |
| 사람에게 넘기기 | `request_user` |

- DOM 스냅샷에는 `e1`, `e2` 같은 요소 참조가 포함되고 모델은 이 참조로 페이지를 조작합니다. 스냅샷 직렬화는 32,000자를 넘지 않습니다.
- `open`과 `screenshot`에 `wait_seconds`(최대 30초)를 주면 대기 후 캡처합니다. 캡처 이미지는 모델의 비전 입력으로도 전달되며, 전체 페이지 캡처는 메모리 남용을 막기 위해 높이 8,000px까지로 제한하고 폭은 1,440px로 맞춥니다.
- 탭 목록에는 안정적인 ID, 제목, URL, 모델이 붙인 라벨과 메모가 포함됩니다. 한 세션의 탭 개수 상한은 `설정 > 도구`에서 정합니다.
- 세션은 대화에 속하며 응답이 끝나도 유지됩니다. 사용자나 모델이 마지막 탭·세션을 명시적으로 닫거나 대화를 삭제할 때만 종료되고, 비활성이나 용량 한도가 기존 세션을 쫓아내지는 않습니다.
- 공개 주소 검사는 최초 탐색뿐 아니라 서브리소스 요청에도 적용됩니다.

### 실시간 브라우저 화면

입력창의 **브라우저 화면 보기**를 켜면 모델이 쓰는 바로 그 Chromium 탭이 채팅 옆 분할 화면에 나타납니다. 사용자는 주소 이동, 클릭, 드래그, 스크롤, 포커스된 입력란 타이핑, 탭 열기·닫기를 직접 할 수 있고, 세션 상태를 잃지 않습니다. 모델이 `request_user`로 사람을 부르면 안내 문구가 표시되고, **조작 완료**를 누르면 모델이 이어받습니다.

데스크톱 환경에서는 화면 밖에 헤디드 Chromium을 띄우고, 디스플레이가 없는 호스트에서는 헤드리스로 대체합니다. 설치된 안정 버전 Chrome/Edge를 우선 사용하며, 화면 밖·백그라운드 스로틀링을 끄고 일반적인 자동화 신호를 억제합니다.

### 브라우저 준비

Docker 이미지와 Windows MSI에는 Chromium이 포함됩니다. 소스에서 직접 실행하는데 Chrome이나 Edge가 없다면 한 번만 설치하세요.

```bash
npm run browser:install
```

별도 실행 파일은 `NEURAL_CHAT_BROWSER_EXECUTABLE`로 지정합니다.

## 저장소 접근

저장소 접근 행의 왼쪽 폴드를 펼치면 **읽기**와 **쓰기**를 따로 켤 수 있습니다. 읽기는 개인 저장소 검색과 모델 컨텍스트 불러오기를 허용합니다. 쓰기는 일반 텍스트(`.txt`)와 Markdown(`.md`)만 새로 만들 수 있으며, 알약형 숫자 필드의 1~20개 대화당 한도를 넘으면 서버가 거부합니다. 쓰기는 기본적으로 꺼져 있습니다.

모델이 **현재 사용자 소유**의 개인 저장소를 검색하고 읽게 합니다. 다른 사용자의 파일과 삭제된 파일에는 접근할 수 없습니다.

| 액션 | 인자 | 결과 |
| --- | --- | --- |
| `search` | `query`, `sort`, `limit`(1~20) | 파일 ID, 이름, MIME 타입, 크기, 생성 시각 |
| `read` | `file_id` 또는 `query` | 종류에 맞는 모델 입력 |

읽기 결과는 종류별로 다릅니다. 이미지는 비전 입력으로, PDF는 추출 텍스트와 필요 시 렌더링된 페이지로, 안전한 텍스트 파일은 디코딩된 텍스트로 전달됩니다. 파일 이름이 모호하면 후보 목록을 돌려주고 모델이 다시 고르게 합니다.

사용자가 첨부 없이 저장된 파일 이름만 언급했을 때 유용합니다.

## 현재 시간과 현재 위치

- `get_current_time` — 사용자의 현재 날짜·시각을 초와 IANA 시간대까지 포함해 돌려줍니다.
- `get_current_location` — 브라우저에 위치를 요청한 뒤 좌표와 역지오코딩 결과(국가, 지역, 도시, 세부 행정구역)를 돌려줍니다. 브라우저 위치 권한이 필요합니다.

## 다중 선택 질문

모델이 선택형 질문으로 사용자의 의도를 좁힐 수 있습니다. 질문은 기술적인 도구 폴딩 대신 **입력창 위의 전용 카드**에 한 번에 하나씩 표시됩니다.

| 질문 유형 | 의미 |
| --- | --- |
| `single_select` | 정확히 하나 선택 |
| `multi_select` | 여러 개 선택 |
| `rank_priorities` | 우선순위 정렬 |

- 한 호출에 담을 수 있는 질문 수는 `설정 > 도구`에서 정합니다(기본 3, 최대 10). 선택지는 질문당 2~4개입니다.
- 답변하면 다음 질문으로 슬라이드 전환되고, 제출한 질문·답변 쌍은 사용자 메시지 형태로 대화에 남은 뒤 모델 응답이 이어집니다.
- 직접 입력란으로 목록에 없는 답을 쓸 수도 있습니다.
- 질문 대기 중에도 생성 중단 버튼이 동작합니다.

## MCP 연결

`설정 > MCP 연결`에서 계정별 원격 MCP 서버를 여러 개 등록합니다. 등록 창에는 이름, 선택 설명, Streamable HTTP 연결 URL, 인증 방식, 연결 사용 여부가 있습니다. 인증은 OAuth 액세스 토큰, API Key, 인증 없음 중 하나이며 OAuth와 API Key 값은 현재 Bearer 토큰으로 전송됩니다. 저장된 인증 값은 설정 응답이나 화면으로 다시 보내지 않습니다.

- 연결 테스트는 서버의 도구 목록을 조회해 접근 가능 여부와 도구 수를 확인합니다.
- 연결 행의 톱니 버튼에서 서버 도구 목록, 설명, 입력 스키마를 확인합니다. 각 도구 정책은 **차단 / 항상 묻기 / 세션마다 묻기 / 항상 허용** 중 하나입니다. 기본값은 세션마다 묻기입니다.
- 차단된 도구는 모델에 전달되지 않습니다. 확인 정책은 실제 실행 전에 사용자 승인을 받고, 세션 승인은 같은 대화에서 재사용됩니다.
- 채팅 메뉴에서는 MCP 연결 단위 스위치와 연결별 폴드가 함께 표시됩니다. 폴드 안의 개별 토글은 현재 대화에서 모델에 전달할 도구만 조정하며, 설정에서 차단한 도구는 켤 수 없습니다. 도구 이름은 연결별 네임스페이스로 분리됩니다.
- 실행 전 승인이 필요한 도구는 승인 카드에 연결·도구 이름, 도구 설명과 핵심 요청 인자로 만든 작업 목적, 전체 인자를 함께 표시합니다. 민감정보로 보이는 인자는 목적 요약에서 제외합니다.
- 텍스트, 이미지, 텍스트 리소스, 구조화 결과를 모델의 후속 입력으로 돌려줍니다. 지나치게 긴 텍스트 결과는 제한합니다.
- 플랜이 MCP를 허용할 때만 등록·테스트·호출할 수 있으며, 사용자별 최대 등록 수는 플랜 설정을 따릅니다. 플랜에서 사용을 끄면 기존 등록 정보는 보존되지만 채팅 도구에서는 숨겨집니다.
- 일반 계정은 공개 주소만 연결할 수 있습니다. 관리자 계정은 사설망 주소도 쓸 수 있지만 링크 로컬·예약 주소와 HTTP 리디렉션은 모든 계정에서 차단합니다.

## 아티팩트

모델이 `create_artifact`로 생성한 결과는 기술적인 도구 로그와 분리된 카드로 표시됩니다. 카드를 열면 화면 전체를 쓰는 전용 뷰어가 나타납니다. 다운로드 옆 **미리보기 / 코드** 세그먼트로 HTML·CSV·JSON·XML·Markdown 모두 렌더링 결과와 원본을 전환합니다.

| 형식 | 표시 방식 |
| --- | --- |
| HTML | `sandbox`가 적용된 독립 웹뷰에서 렌더링 및 스크립트 실행 |
| CSV | 고정 헤더와 스크롤을 지원하는 표 |
| JSON, XML | 중첩 항목을 접고 펼칠 수 있는 트리 |
| Markdown | GFM 문서 렌더링 |

HTML은 실행 결과만 보여 줍니다. CSV, JSON, XML, Markdown은 편집 모드에서 원본과 렌더링 결과를 나란히 확인할 수 있고, 저장한 변경은 현재 대화의 도구 결과에 반영됩니다. 모든 형식은 원본 파일로 다운로드할 수 있으며 도구 입력은 UTF-8 기준 1MB로 제한됩니다.

## 호스트 컴퓨터 (실험 기능)

NeuralNetUI를 실행 중인 **컨테이너가 아닌** 컴퓨터를 모델이 조작하게 하는 도구입니다. 가장 강력하고 가장 위험하므로 세 겹으로 제한됩니다.

1. 관리자가 `설정 > 실험실`에서 기능을 켜야 하고,
2. **Superadmin 계정에만** 도구가 노출·실행되며(서버가 역할·기능·환경을 모두 검사),
3. 모든 액션은 신뢰 정책을 통과해야 합니다.

### 액션

| 분류 | 액션 |
| --- | --- |
| 파일 | `search_files`, `inspect_path`, `read_file`, `copy`, `write_file`, `rename`, `move`, `delete` |
| 저장소·공유 | `store_file`(개인 저장소로 가져오기), `upload_temp`(외부 임시 공유) |
| 프로세스 | `start_process`, `list_processes`, `kill_process` |
| 셸 | `run_shell` (`powershell` 또는 `bash`) |
| 화면 | `screenshot` |

호스트 파일을 첨부·표시·업로드해 달라는 요청은 기본적으로 할당량이 적용되는 **소유자 전용 개인 저장소**(`store_file`)로 갑니다. 외부 임시 링크는 사용자가 명시적으로 요구할 때만 씁니다. 시작한 백그라운드 프로세스의 PID와 이름은 해당 대화 범위에서 추적됩니다.

Windows 서비스 설치에서는 세션 0을 캡처하지 않고, 로그인한 사용자의 트레이 프로세스가 호스팅하는 named pipe 브리지를 통해 실제 대화형 데스크톱을 캡처합니다.

### 신뢰 모드

`설정 > 도구`의 하네스 영역에서 정합니다.

| 모드 | 동작 |
| --- | --- |
| 신뢰 없음 (기본) | 모든 액션이 승인 대기 |
| 부분 신뢰 | 27행 권한 매트릭스에서 행마다 자동 허용 또는 항상 확인을 선택. 매트릭스에 없는 액션은 항상 승인 대기 |
| 완전 신뢰 | 승인 없이 실행 |

권한 매트릭스는 파일 액션을 개별로 나누고, 덮어쓰기·재귀 삭제 같은 파괴적 변형을 별도 행으로 둡니다. PowerShell과 Bash는 각각 위험도 1~5의 다섯 행을 가집니다.

| 위험도 | 기준 |
| --- | --- |
| 1 | 파일 내용을 읽지 않는 상태·메타데이터 조회 |
| 2 | 파일 내용 읽기 |
| 3 | 생성·수정·복사·이름 변경·이동·프로그램 실행 |
| 4 | 되돌릴 수 없는 삭제나 종료 |
| 5 | 컴퓨터 구성 변경 또는 호스트 도구 목적을 벗어난 작업 |

### 승인 카드

신뢰되지 않은 액션은 위험도, 실제 대상(파일·폴더·프로그램·목적지·설정)을 짚은 구체적 설명, 전체 인자와 함께 승인 카드에 대기합니다. 설명은 줄바꿈을 유지하고 최대 6줄 뒤부터 세로 스크롤되며, 전체 인자 상자는 가로·세로로 스크롤됩니다. 선택지는 **허용**, **거부**, **거부 후 다른 작업 지시** 세 가지입니다. 승인하면 카드가 즉시 활성 도구 상태로 바뀝니다.

PowerShell·Bash 명령의 위험도 평가는 **채팅 기록 없이 명령만** 전달하는 별도 모델 완료로 수행합니다. 명령은 지시가 아닌 데이터로 취급되며, 파이프라인·치환·인코딩·연쇄 명령 어디에 있든 가장 높은 위험 효과로 분류합니다. 평가에 실패하거나 난독화가 의심되면 위험도 5로 처리합니다. 평가용 모델과 강도, 프롬프트는 하네스 설정에서 바꿀 수 있습니다.

## 실행 규칙과 한도

- 도구 호출은 **순차 실행**입니다. 병렬 호출 한도가 없는 이유입니다.
- 실행 중 **생성 중단**을 누르면 현재 도구에 취소 신호를 전달합니다. 장시간 호스트 셸 명령은 자식 프로세스 트리까지 종료하고, 진행 중인 브라우저 세션은 닫아 페이지 작업을 즉시 끊으며, 웹·저장소·파일 처리 작업도 다음 취소 지점에서 중단됩니다.
- 한 응답의 최대 도구 라운드는 `설정 > 도구`에서 정합니다(기본 8, 최대 10,000).
- 저장된 도구 호출·결과 쌍은 후속 요청에서 복원되어 모델이 맥락을 잃지 않습니다.
- 도구가 만든 이미지 중 보존 대상은 미첨부 업로드 정리에서 제외됩니다.
- 관리자가 입력한 모든 한도 값은 서버의 안전 범위 안에서 검증됩니다. 전체 목록은 [설정 레퍼런스](../settings-reference.md#도구-탭-관리자)에 있습니다.
