# Reasoning

## 프리셋 종류

`설정 > 추론`에서 모델별 Reasoning 템플릿을 관리합니다. 서버가 알려준 옵션으로 프리셋을 자동 생성하지 않습니다(이전의 Built-in Fast/Thinking/Default는 제거되며, 저장된 것도 정규화 시 사라집니다). 채팅의 추론 선택기에는 템플릿만 표시되고, 템플릿이 하나도 없는 모델은 `reasoning_effort` 없이 모델 자체 기본 추론으로 동작합니다(선택기에는 템플릿이 없다는 안내만 보이며, 시스템 프롬프트 편집은 그대로 쓸 수 있습니다).

템플릿은 이름이 레이블이고, **설명**을 적으면 채팅의 추론 선택 창에서 이름 아래에 그 문구가 표시됩니다(비우면 API 값에 맞는 추론 강도 설명, 최대 200자). 템플릿은 직접 입력한 **API로 전송할 값**을 그대로 `reasoning_effort`로 전달한 뒤(비우면 생략), 템플릿 내용을 모델/alias 시스템 프롬프트와 조합합니다.

커스텀 템플릿의 시스템 프롬프트는 세 가지 방식으로 모델 프롬프트와 합쳐집니다.

| 모드 | 결과 |
| --- | --- |
| `replace` | 모델 프롬프트를 템플릿으로 대체 |
| `prepend` | 템플릿을 앞에 붙임 |
| `append` | 템플릿을 뒤에 붙임 (기본) |

템플릿의 공개 범위는 **Global** / **Private** 토글로 정하며 관리자에게만 보입니다(기본 Private).

- **Private**: 만든 사람에게만 보입니다.
- **Global** (`global: true`): 그 모델을 쓸 수 있는 모든 계정에 보입니다. 관리자만 만들거나 수정·삭제할 수 있고, 다른 관리자가 수정해도 작성자는 유지됩니다. 작성자 계정을 삭제해도 남습니다. 일반 계정이 보낸 `global` 값은 서버에서 무시됩니다.

소유권과 순서는 능력 정보가 갱신되어도 유지됩니다.

## 능력 감지

| 드라이버 | 근거 |
| --- | --- |
| OpenAI API | `/models` 메타데이터와 잘 알려진 reasoning 모델 이름 |
| LM Studio | `/api/v1/models`의 `capabilities.reasoning.allowed_options` 우선 |
| NNUI Server | `/v1/models` 메타데이터와 잘 알려진 reasoning 모델 이름. 실제 옵션 처리는 llama.cpp 모델·빌드에 따름 |

감지 결과는 설정에서 언제든 수동으로 덮어쓸 수 있습니다. 모델마다 **추론 전달 방식**을 **API** 또는 **시스템 프롬프트**로 고릅니다(관리자, 서빙 모델만). 서버가 옵션 목록을 제공하지 않는 모델에서 **API**를 고르면 `off`·`minimal`·`low`·`medium`·`high`·`xhigh`·`max`를 강제로 전송해 볼 수 있으며(`reasoningForceApi`), 이때도 채팅의 추론 선택기에는 대체 값이 아니라 이 모델에 만든 템플릿만 표시됩니다. 이 설정은 재감지에도 유지되다가 서버가 실제 옵션을 알려 주면 그 옵션으로 대체됩니다. 서버가 받아들이지 않는 값은 요청 오류가 될 수 있습니다. alias의 reasoning 능력은 실제 기반 연결을 따르며, 기반을 바꾸거나 다시 감지해도 올바르게 갱신됩니다. 오래된 설치라면 모델을 다시 감지하고 저장해 레거시 메타데이터를 갱신하세요.

### 서버 옵션의 해석

서버가 알려준 옵션은 템플릿 편집기의 **API로 전송할 값** 자동완성 후보로만 쓰입니다. 템플릿의 값은 매핑 없이 입력한 그대로 전송됩니다(추론 전달 방식이 API일 때만).

## 이전 추론 전달 (생각 기록 기억하기)

이전 assistant 응답의 `reasoning_content`를 다음 요청에 포함할지는 관리자가 `설정 > 모델`에서 모델마다 정합니다. 기본값은 꺼짐이며, 서버가 요청이 아니라 모델 설정을 기준으로 적용합니다. 별칭은 따로 정하지 않으면 실행 중인 기반 모델의 값을 따릅니다. 컨텍스트 사용량 추정도 선택한 모델의 값을 따릅니다.

## 시스템 프롬프트 편집

입력창 Reasoning 메뉴의 **시스템 프롬프트 편집하기**는 전용 창을 엽니다. 창 위쪽에서 추론 프리셋을 고르면, 그 프리셋이 적용된 모델의 전체 시스템 프롬프트(모델 프롬프트와 템플릿 프롬프트를 합친 결과)가 표시되고 편집할 수 있습니다.

- 편집 내용은 내 계정의 모델·프리셋 조합에만 저장되며(`preferences.systemPromptOverrides`), 다른 사용자와 모델 설정은 바뀌지 않습니다.
- 별칭 모델은 누구나 편집할 수 있습니다. 서빙 모델은 관리자가 `설정 > 모델`에서 **시스템 프롬프트 편집 허용**을 켠 경우에만 버튼이 보이고, 서버도 같은 조건으로 저장과 적용을 확인합니다.
- **기본값으로 되돌리기** 후 저장하면 사용자 지정 프롬프트가 지워지고 모델 설정의 프롬프트로 돌아갑니다.

## 표시

- 추론 생성 중에는 최근 내용이 약 5줄 높이로 스트리밍됩니다.
- 완료되면 실제 측정한 소요 시간이 `Thought for …` 또는 `… 동안 생각함`으로 표시됩니다.
- 모든 추론 관련 아이콘은 전구(Lightbulb)이며, 추론 폴딩은 왼쪽 선 없이 오른쪽/아래 방향 셰브런을 씁니다.
- 실시간 추론 영역은 전사와 별개로 자동 추적을 멈추고 재개할 수 있습니다.

## 프리셋 설명

`설정 > 모양`의 **추론 설명 표시**를 켜면 채팅 선택기에 각 강도의 설명이 함께 보입니다. 강도별 설명은 직접 덮어쓸 수 있고, 비워두면 현재 언어의 기본 문구로 되돌아갑니다. 따라서 언어를 바꿔도 손대지 않은 설명은 그대로 읽을 수 있습니다.

## 기본 추론 강도

Reasoning 선택기 하단의 **기본으로 사용**으로 계정별 기본 강도를 저장합니다. 저장하지 않았으면 모델의 템플릿 목록 맨 위 항목이 기본으로 선택됩니다. alias의 기반 모델은 이제 Reasoning 선택기가 아니라 모델 선택기에서 고릅니다([모델](models.md#커스텀-모델-alias) 참고).
