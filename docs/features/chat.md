# 대화

## 브랜치 구조

대화는 단일 목록이 아니라 **브랜치 트리**입니다. 다음 세 가지 조작은 모두 기존 경로를 보존한 채 새 브랜치를 만듭니다.

- 사용자 메시지 편집
- 모델 응답 편집
- 응답 재생성

수정본이 있는 메시지 아래에는 `< m / n >` 탐색기가 나타나고, 이것으로 해당 메시지의 이전·다음 수정본과 그에 연결된 채팅 기록을 즉시 전환합니다. 완료된 모델 응답은 응답 아래 편집 버튼으로 현재 브랜치 안에서 직접 고칠 수도 있습니다.

사용자 메시지를 삭제하면 같은 브랜치에서 바로 연결된 모델 응답도 함께 삭제됩니다.

## 응답의 단계 기록

한 번의 모델 응답 안에서 추론, 본문, 도구 호출, 컨텍스트 압축은 서로 번갈아 일어납니다. 각 assistant 메시지는 이 순서를 `steps` 배열로 그대로 보존합니다.

| 단계 | 내용 |
| --- | --- |
| `reasoning` | 추론 텍스트와 소요 시간 |
| `content` | 사용자에게 전달된 본문 |
| `tools` | 그 시점에 실행된 도구 호출 묶음 |
| `compaction` | 컨텍스트 압축의 요약·추론·유지된 도구 호출 |

`content`와 `reasoning` 필드는 여전히 전체 연결본이므로 복사, 내보내기, 상위 모델에 보내는 이력은 영향을 받지 않습니다.

## 임시 채팅

임시 채팅은 기록과 검색에서 제외되고, 대화가 끝나면 정리됩니다. 첫 메시지를 보내기 전에는 모드 버튼으로 작성 중인 초안을 유지한 채 일반 채팅으로 되돌릴 수 있고, 메시지를 보낸 뒤에는 같은 버튼이 대화를 **일반 대화로 승격**합니다. 임시 채팅은 배경 액센트만 중립 회색으로 바뀌어 한눈에 구분됩니다.

## 생성 제어

- **중단** — 생성 중 언제든 중단할 수 있습니다. 선택형 질문 대기 중에도 중단 버튼이 동작합니다.
- **메시지 큐** — 생성 중에 입력한 메시지는 큐에 쌓였다가 순서대로 전송됩니다.
- **대기 상태 표시** — 세션 대기, 공간 확보, 모델 로드, 서버 대기, 응답 준비, 프롬프트 처리, 컨텍스트 압축 상태가 입력창 위에 표시됩니다.
- **복구** — 서버 재시작 등으로 선택형 질문 작업이 사라졌다면, 대화를 다시 열 때 일반 입력이 복구됩니다. 저장에 실패한 클라이언트는 보내지 못한 초안을 되살립니다.

## 첨부

이미지, PDF, 일반 파일을 메시지에 함께 첨부할 수 있습니다.

| 종류 | 처리 |
| --- | --- |
| 이미지 | 원본은 개인 저장소에 보존. 브라우저가 만든 경량 썸네일을 목록에 사용 |
| PDF | 원본과 제한된 텍스트 추출 캐시를 보관. 텍스트가 없는 스캔 PDF는 요청 시 제한된 페이지만 임시 이미지로 렌더링하고 즉시 삭제 |
| 기타 파일 | 시그니처로 확인된 래스터 이미지·PDF만 인라인 표시하고 나머지는 다운로드 |

붙여넣기로 이미지를 첨부할 수 있습니다. 클립보드에 텍스트와 이미지가 함께 있으면 텍스트가 우선합니다. 입력창의 저장소 버튼으로 이미 저장된 파일을 골라 붙일 수도 있습니다([개인 저장소](storage.md) 참고).

메시지당 첨부 개수와 각 용량 한도는 `설정 > 도구`에서 정합니다.

## 렌더링

- 모델 응답은 **GitHub Flavored Markdown**과 **KaTeX** LaTeX로 렌더링됩니다. 목록, 링크, 표, 인라인·블록 수식, 인라인 코드와 코드 블록을 지원합니다.
- 사용자 메시지는 입력한 일반 텍스트 그대로 표시됩니다. 긴 URL처럼 공백이 없는 문자열은 말풍선 안에서 자동 줄바꿈되어 채팅 폭을 유지합니다.
- `설정 > 모양`에서 모델 identifier 표시와 단일·이중 물결표 취소선 렌더링을 계정별로 켜고 끌 수 있습니다. 취소선 렌더링을 끄면 원본 물결표가 그대로 보존됩니다.
- 이미지는 첨부와 Markdown 모두 거의 전체 화면 라이트박스로 열립니다.

### 입력 키

| 환경 | Enter | Shift+Enter |
| --- | --- | --- |
| 데스크톱 | 전송 | 줄바꿈 |
| 모바일·터치 | 줄바꿈 | — |

## 스크롤

응답 스트리밍 중에는 사용자가 대화 하단을 보고 있는 동안에만 새 내용을 자동으로 따라갑니다. 위로 스크롤하면 자동 추적이 멈추고 아래 화살표 버튼이 나타나며, 다시 하단으로 이동하면 추적이 재개됩니다. 실시간 추론 영역과 전체 전사가 각각 독립적으로 이 규칙을 따릅니다.

긴 대화는 최근 60개 메시지만 먼저 렌더링하고, 이전 메시지를 60개 단위로 추가 표시합니다. 사이드바 기록은 전체 대화 대신 SQLite 요약 쿼리만 읽습니다.

## 도구 활동 표시

한 응답에서 일어난 도구 호출은 렌치 아이콘이 붙은 하나의 **도구 사용 중 / 도구 사용함** 폴딩에 모입니다. 각 호출은 이름과 상태를 보여주는 하위 폴딩이며, 펼치면 호출 인자와 결과를 확인할 수 있습니다. 진행 중인 호출은 자동으로 펼쳐지고, 완료된 호출은 접힌 상태로 정리됩니다.

활성 대화의 눈 아이콘을 누르면 기술 활동(추론·도구 폴딩)을 숨길 수 있습니다. 이 토글은 대화별 임시 상태이며 새로고침하면 초기화되고, 사용자 질문·답변 말풍선은 숨기지 않습니다.

## 검색과 관리

- **검색** — 사이드바의 검색은 사용자가 소유한 **모든 브랜치**의 원본 내용을 읽어 최대 100건의 브랜치 일치와 스니펫을 돌려줍니다. 현재 활성 브랜치가 아닌 결과는 따로 표시됩니다.
- **채팅 관리하기** — 기록 맨 아래의 관리 모달에서 제목·내용·ID로 검색하고, 비활성 시간/일수로 거르고, 페이지를 넘나들며 선택해 삭제하거나, 필터에 걸린 전체를 삭제할 수 있습니다. 목록은 10개 단위로 페이징됩니다.
- **이름 변경** — 기록 행의 hover 액션에서 대화 이름을 바꿉니다. 수동으로 지정했거나 생성된 제목은 뒤늦게 도착한 전체 저장으로 덮어써지지 않습니다.

## 내보내기

대화 메뉴의 **채팅 내보내기**는 두 형식을 지원합니다.

| 형식 | 범위 |
| --- | --- |
| Markdown | 현재 선택된 브랜치 |
| JSON | 모든 브랜치 |

추론 내용을 내보내기에 포함할지는 `설정 > 일반`에서 정합니다.

## 삭제와 보존

대화 삭제는 진행 중인 생성 작업도 함께 폐기합니다. 삭제된 대화와 파일은 곧바로 사라지지 않고 **휴지통**으로 이동하며, 워크스페이스에 설정된 보존 기간(1~60일) 동안 보관됩니다. 자세한 내용은 [개인 저장소](storage.md)를 참고하세요.
