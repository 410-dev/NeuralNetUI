# 3.0.0-rc3-b22 — MCP tool policies and artifacts

## Scope

- Added persisted per-tool MCP policies and server-side enforcement.
- Added per-conversation MCP tool selection in the composer.
- Added the artifact tool and HTML, CSV, JSON, XML, and Markdown viewers.
- Added non-HTML artifact editing with conversation persistence.
- Updated backup coverage, version metadata, documentation, and tests.

## Safety and behavior

- Blocked MCP tools are omitted before model inference. Always-ask tools pause every invocation; session-ask tools reuse approval only for the same user, conversation, connection, and tool. Stale approvals expire after 12 hours and conversation deletion clears them.
- HTML artifacts use a sandboxed iframe without same-origin or top-navigation permission. Artifact payloads are capped at 1 MB.
- Tool policies remain owner-scoped through the MCP connection foreign key and are included in personal and account backup images.
