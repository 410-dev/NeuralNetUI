# 3.0.0-beta.13 validation

## Scope

- Moved every long-text edit into the shared large modal already used for harness prompts: sent-message editing, model-answer editing, a model's system prompt, and a reasoning template's additional prompt. All four use the same dialog shell and the same Cancel/primary button arrangement.
- Kept both settings prompts visible in place as read-only fields with a **프롬프트 편집 / Edit prompt** action beneath them instead of removing the field. The reasoning template's prompt now spans the full editor width rather than the 170px label column.
- Replaced every remaining native browser dialog (nine `window.confirm` call sites across chat history, message deletion, chat management, storage references, user management, and administrator audit) with one in-app message box that traps focus, closes on Escape, and makes the background inert.
- Gave the message box four tones: danger for irreversible work, warning for recoverable deletion, info for an explanation, and success for a completed action. The mark, detail rule, and confirming action all take the tone's colour.
- Hid the sent-message regenerate/copy/edit/delete actions until the pointer approaches. The hover target is the whole conversation row, extended 12px into the gaps above and below without moving the message; coarse pointers keep the actions visible.
- Added breathing room under an expanded tool group and removed the rules between tool groups, while keeping the rule that separates file attachment from the tool list.
- Moved **저장소 접근 / Storage access** out of the Agent group and into the file-attachment section beneath **저장소에서 파일 불러오기**, and renamed the first attachment action to **이미지 또는 PDF 업로드 / Upload images or PDFs**. The Agent group is hidden when neither the browser nor host-computer tool is available.
- Added **복제하기 / Duplicate** beside the save in the chat rename dialog. It stays disabled until the title actually differs and copies the whole chat, every branch included, under new conversation, branch, and message identifiers with active branch, parent branch, fork point, and revision group remapped to match.
- Made the chat-history download action available with no chat selected, exporting every saved chat as one ZIP holding an index plus one JSON file per chat, honouring the existing reasoning-inclusion preference.
- Made message deletion ask its scope when the same request exists in more than one branch: **이 분기만 / This branch only** or **모든 분기 / Every branch**. Emptied and now-identical branches are folded away and the active branch follows.
- Bumped the application and package display version to `3.0.0-beta.13`.
