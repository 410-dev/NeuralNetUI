# 3.0.0-beta.7 validation

## Personal storage

- The personal storage capacity meter uses a visible long grey track with a white fill. Ordinary users do not see trash or delete controls.
- Direct upload accepts multiple files. Each file uses an authenticated owner-scoped upload session and 8 MiB requests with bounded retries, keeping every request below Cloudflare Tunnel's 100 MB limit. Completion verifies all chunks and the final byte count before atomically registering the file against the user's quota.
- The create-file modal accepts a filename and content, uses the shared dropdown design for Markdown or text, and renders GFM/KaTeX preview in Markdown mode. Saving writes the `.md` or `.txt` file directly to private storage.
