# 3.0.0-beta.1 validation

## Scope

- Add one opt-in experimental `host_computer` agent tool for non-containerized hosts, exposed only to Superadmin accounts.
- Support bounded file search/inspection/read/write/copy/rename/move/delete, `temp.hysong.dev` uploads, conversation-scoped background programs, PowerShell/Bash, and model-visible full-screen capture.
- Add full-trust, partial-trust five-level matrix, and no-trust harness policies, with no trust as the default.
- Analyze every PowerShell/Bash command through a context-isolated model request and present localized, concrete risk explanations before any action that requires approval.
- Preserve native LM Studio `prompt_processing` status and percentage through ordinary response gaps, showing server-waiting state only after 30 seconds without a response.
- Raise the application version to `3.0.0-beta.1` and MSI ProductVersion to `3.0.0`.

## Architecture and safeguards

- Authorization is enforced on the server from authenticated role, workspace feature flag, and runtime container detection. Client-provided tool flags cannot grant access.
- Dedicated file operations use resolved absolute paths, bounded reads/writes/searches, literal process arguments, atomic file replacement, filesystem-root deletion protection, and conversation ownership for process termination.
- Shell assessment sends only language, shell, command, and working directory to the selected assessment model. Chat history is excluded. Invalid or failed assessments fail closed at risk level 5.
- Approval cards show the risk level, concrete localized explanation, and complete action arguments, with allow, deny, and deny-with-redirection outcomes.
- Windows service execution is marked with `NEURAL_CHAT_WINDOWS_SERVICE=1`; screenshots are requested over `NeuralNetUI.HostAgent` from the signed-in user's tray process so the actual interactive desktop is captured instead of Windows service session 0. The tray accepts bridge requests only from a LocalSystem client, matching the MSI service account.
- Screenshot pixels are supplied to the model for the current tool round while persisted tool results retain only metadata, avoiding base64 image duplication in conversation storage.
- LM Studio response-header, response-body, and streaming-read watchdogs use the same 30-second threshold. Each received progress event restores `processing-prompt`, so prompt percentage remains authoritative while the server is active.
