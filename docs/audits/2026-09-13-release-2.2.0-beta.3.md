# 2.2.0-beta.3 validation

## Scope

- Preserve native LM Studio `prompt_processing` progress after an assistant tool round and position it below the completed tool fold.
- Stream compaction-model reasoning and partial summary into the active context-compaction fold.
- Count tool calls/results in the context donut and immediately replace covered history with an active compaction summary.
- Keep shared-browser tabs alive across completed model responses and inactivity. Only explicit user/model tab or session close, last-tab close, conversation deletion, or process shutdown ends the in-memory session.

## Architecture and safeguards

- Native LM Studio history remains eligible when reasoning is attached to the current assistant tool request; tool roles, IDs, and content remain intact.
- Compaction streaming updates the existing transcript step and broadcasts batched snapshots. Completion fills the same step rather than creating a duplicate.
- The latest compaction step supplies both a message and step boundary, excluding covered response, reasoning, and tool estimates while preserving later material.
- Browser ownership is conversation-scoped. Inactivity cleanup and capacity eviction were removed; opening beyond the per-conversation or global session cap returns an actionable error without closing existing work. Explicit conversation deletion closes its sessions.
