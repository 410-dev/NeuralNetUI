# 2.1.5 validation

## Scope

Temporary-chat presentation and icon-only mode controls; clean new-chat URLs; model-picker checks; clipboard attachments; editable randomized greetings; account display-name group. No database migration.

## Automated

- 117 unit tests passed, including clipboard text/image routing, randomized greeting selection without immediate repeats, localized overrides, blank fallbacks, repeated name placeholders, duplicate choices, and malformed preference normalization.
- TypeScript checking and final production build passed. No lint command/configuration exists in this repository; `git diff --check` is used for patch whitespace validation.
- Isolated API check passed: ordinary users can save their own display name and greetings; the administrator account is unchanged; six greetings in one band are rejected.
- Existing progress integration script still expects the obsolete `progressUnavailable` snapshot property removed before this release. The unchanged script fails that assertion. A temporary copy omitting its two obsolete property assertions passed standard-host isolation, unsupported experimental fallback, and progress preference persistence. No real model-server inference was used.

## Interactive browser checks

Tested using the in-app browser against isolated temporary databases and a mock model server.

- Temporary idle screen shows the requested Korean heading/subtitle with no top explanation. Computed background is neutral RGB 128/128/128 while the regular accent remains RGB 77/127/216.
- Both mode-switch controls have empty visible text, one icon, and accessible labels/tooltips; width is 36px. Before starting, returning to regular mode preserves the draft. After sending, the control changes to Save this chat and the persisted conversation gains its URL.
- New Chat returns to `/`; refreshing stays there without a missing-conversation message.
- Model dropdown contains no model icon; the selected check centre matches the row centre within subpixel rounding.
- Text paste remains native. Valid PNG clipboard data creates an attachment; malformed PNG and mismatched signatures are rejected by the existing upload validator.
- Appearance displays seven expandable time bands and five fields per band. Saving five custom midday lines and a new name displays a custom line with the new name. Reloading the main page changes the greeting.
- Account settings contains separate display-name/password groups. Both use 17px padding, 1px borders, input x=257 and label x=259 in the inspected viewport. Saved display name updates the account heading and sidebar.

## Limits

No MSI installation/upgrade execution or macOS Command+V test was performed. Windows Chromium clipboard paste was exercised. The package is unsigned.
