# 3.0.0-beta.11 validation

## Scope

- Styled the per-model maximum-long-edge input with the shared neutral pill field language, including disabled and focus states.
- Removed the Manage chats launcher icon and session icons from both Manage chats and Chats using this file.
- Fixed Manage chats at ten sessions per page. While selection mode is active, clicking a session body toggles that session instead of navigating.
- Changed chat-session containers to full pills in both dialogs.
- Increased personal-storage card radius to 22px and made the preview's top and bottom spacing equal.
- Fixed an existing response race: aborting the first responsive page-size request can no longer turn a successful-but-interrupted JSON parse into an empty object that crashes the dialog.

- Packaged-standalone Beta 11 Chromium integration: passed using `installer/build/stage/node.exe` and the staged app.
