# 3.0.0-rc2-b21 — settings, connection labels, MCP visibility, and token fades

## Scope

- Rebuild the model list immediately after a model-server connection is removed.
- Show each model's connection name in the chat picker and the model/reasoning settings lists.
- Enlarge the desktop settings panel and make the mobile settings body a bounded, fully reachable scroller.
- Hide MCP settings for plans without MCP access and restore spacing between the plan summary and connection rows.
- Remove response pacing and render every received fragment immediately; `instant` uses 0ms and `fade` exposes an 80–800ms per-fragment duration.
- Keep rendered Markdown and code-snippet chrome stable while only newly appended text fades.
- Preserve the existing independently anchored usage-window reset behavior.

## Validation

- `npm test`: 184 tests passed.
- `npx tsc --noEmit`: passed.
- `npm run build`: passed with Next.js 16.3.3.
- Browser QA used an isolated temporary database at a narrow mobile viewport. The MCP tab was absent for the default MCP-disabled plan; the appearance page contained no response-pacing control; enabling Soft fade revealed the 240ms token-duration slider; scrolling reached the slider and bottom actions; no browser warnings or errors were reported.

The temporary QA account/database was removed after validation. No MSI was built as part of this source change.
