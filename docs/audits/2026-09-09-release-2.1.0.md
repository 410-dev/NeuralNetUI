# 2.1.0 validation

## Scope

Adds temporary chats (schema migration 9), the product mark and favicon, time-of-day greetings, customizable reasoning descriptions, and two mobile gesture and layout fixes. Chat streaming, connection drivers, residency and harness behaviour are unchanged. Existing conversations default to `temporary = 0`, so nothing already saved changes.

## Automated

- Unit suite: 92 passed. New `lib/greetings.test.ts` covers band coverage for all 24 hours including the wrap past midnight, five distinct lines per band per language, stability within a day and rotation across days. `lib/appearance.test.ts` gained coverage for reasoning-note fallback per language, override trimming and unknown-key rejection.
- Type checking: `npx tsc --noEmit` passed. Production: `npm run build` passed.

## Interactive

Driven in a browser against a throwaway data directory and a mock OpenAI-compatible model server, seeded through the API the way `scripts/test-harness-integration.mjs` does.

- Temporary chat, end to end: pressing the top-right control starts one; a full request and streamed response stayed absent from the history list; the control became "이 채팅 저장" with the hint line. Saving added it to history under a harness-generated title. Starting a new chat after another temporary exchange left the abandoned conversation returning 404, so it was genuinely removed.
- Reasoning picker with eight effort levels: the popover clamps to 420px, sits fully inside an 820px viewport (top 12, bottom 432) and scrolls internally. Each option shows its description, and the send-reasoning switch reads "생각 기록 기억하기".
- Appearance panel: the reasoning-description card carries the show toggle plus eight fields labelled Fast through Max, each with the built-in wording as its placeholder.
- Product mark: model rows and chat-picker rows for served models render the seven-node network glyph; aliases keep a pencil. `/icon.svg` is served as `image/svg+xml` and linked from the document head.
- Greetings: the morning band produced a rotating line; `word-break: keep-all` stopped the Korean greeting breaking mid-word, and the narrow layout wraps it inside 263px of a 375px viewport (70%).
- Gestures: `overscroll-behavior: none` is computed on both `html` and `body`, with `contain` on the thread, history and settings scrollers.
- A geometry sweep of the chat screen reports no off-centre rows.

## Not verified

- Pull-to-refresh was addressed by CSS and confirmed only as computed style; the gesture itself was not reproduced on a real phone.
- The tray host change (no browser at sign-in) was verified by compiling it into the MSI, not by signing out and back in. The Start menu shortcut still passes `--open` and the post-install launch still opens the UI once.
- The promotion title path was exercised against a mock model, so real title quality is unmeasured.
- Only Chromium was exercised.
- The MSI was packaged without installing it or restarting the user's service.

## Notes

- A temporary chat is written to the database while it is open because the streaming pipeline needs a conversation row to write into. It is excluded from history and search, skipped by the sweep only while a chat job is live, and deleted as soon as the client stops naming it. "Not saved" therefore means "never enters your history and is removed when you leave", not "never touches disk".
- `screenshot` captures from the Browser pane's mobile preset render at half scale inside the image; layout was judged from DOM geometry rather than those images.
