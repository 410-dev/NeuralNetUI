# 3.0.0-beta.14 validation

## Scope

This release answers a design-language audit of the Beta 13 tree. Nothing new was added; the
interface was brought back onto the rules `design/MASTER.md` already states, and the rules were
extended where the audit showed the document was silent.

- **Corners.** The stylesheet held 99 hand-written pixel radii against 68 token uses, and the most
  common corner in the whole file — 17px, 23 rules — had no token at all. Every corner now comes
  from one ladder: pill, `xl` for shell panels, `lg` for dialogs and popovers, `card` for cards and
  grouped panels, `md` for the rows and options inside them, `sm` for small containers, `xs` for
  icon marks, `media` for thumbnails. Zero literal radii remain. `--radius-sm` was retuned from
  15px to 17px so the file's real working corner is the one the token names, and six rules that
  wrote `40px` as a stand-in for a pill now say pill; at those control heights the two render
  identically. `--radius-card` keeps cards and grouped panels one step above the rows inside them,
  which is the distinction the Beta 11 storage-card assertion already encoded.
- **Signals.** Danger was thirteen different colours — `#e59690`, `#e6a09b`, `#efaaa7`, `#f0b0ab`,
  `#e4a6a3`, `#ff9b9b`, `#df6664` and six washes, one of them (`rgba(255,90,90,…)`) from a visibly
  different family. Each signal now owns one hue and states its roles: `--danger` / `--danger-text`
  / `--danger-soft` / `--danger-wash` / `--danger-line`, plus `--warning` and `--success`. Warning
  and success absorbed their own scattered values the same way.
- **Secondary type contrast.** `--dim` was `#74777e`, which reaches 4.5:1 against **no** surface in
  the file — 4.41:1 on the darkest background, 3.35:1 on `--panel-raised` — while carrying 96 uses,
  nearly all of them 8–10px labels. It is now `#8b8e95`, which clears 4.5:1 against every surface
  the file defines (4.58:1 at worst). Two colours that were quieter still and did hold words,
  `#63666c` on the composer note (3.44:1) and `#5a5c62` on the token-rate units (2.96:1), fold into
  it. The type floor moved from 7px to 9px; 29 rules sat below it.
- **Icon marks.** MASTER.md's "colour and a slight scale, never a filled background" described four
  rules; fifteen-plus icon-only controls grew a plate instead, including two — the composer's add
  button and the assistant footer's copy button — that sit a few hundred pixels apart. The whole
  family now shares one answer, with a danger variant for the marks that remove something.
  Labelled controls keep their filled hover, because a row is not a mark. The lightbox close keeps
  its scrim: it sits over a picture rather than over a surface.
- **Keyboard focus.** Outside one image rule the interface had no focus ring; fields signalled
  focus only by tinting a border from 17% to 55% white, and a listbox option's focus style was
  identical to its hover style. Controls now take an outline ring and fields take the same ring as
  a shadow, since their own rules clear the outline to keep the pill edge clean. A focused option
  reads as accent-filled rather than as an ordinary hover.
- **Dialogs.** `MobileMessageActions` and `ImageLightbox` both declared `role="dialog"` and
  `aria-modal="true"` while implementing none of it — no trap, no inert background, no restored
  opener, and in the sheet's case no Escape. Both now take `useModalFocus` like every other dialog.
- **Where a dialog opens its keyboard.** Because header controls come first in the markup, every
  dialog opened with focus on Close — including "Search chat history", where the person then had to
  Tab before typing, and the audit browsers, where Enter on the focused control closed the screen
  just opened. `useModalFocus` now honours a `data-autofocus` field, and the five search dialogs
  name theirs.
- **Popover placement.** `SelectMenu` chose up or down against `window.innerHeight`, but the box
  that actually clips it is the settings pane or the dialog body, which on a tall window ends far
  above the viewport. The decision now runs against the nearest scrolling or hidden ancestor, and a
  list that outgrows a narrow trigger sideways anchors to whichever edge keeps it inside.
- **The model name.** `.model-trigger > span` had no truncation and the surface actions are
  positioned over the chat, so a long model name ran underneath them; at 420px the measured title
  was 433px wide inside a 182px box. The title now reserves the actions' side of the row, respects
  the room it is given, and truncates. Its 19px size steps down on narrow screens.
- **Touch targets.** Four icon marks below 28px (one of them 27×28, not square) are now 28px.
- **One voice for absence, waiting and notices.** Five different "nothing here" treatments now
  share one colour, size and rhythm; the dashed block stays reserved for the state that asks the
  person to add something. The two loading blocks match. `.settings-notice` became a bordered
  message rather than 10px of loose text under a form, keeping its neutral key because those lines
  report completed work as often as failures.
- **Document language.** `<html lang>` was hard-coded to `ko` and never updated, so an English
  interface was announced to assistive technology in a Korean voice. It now follows the chosen
  language. Three `aria-label="Close"` literals and one hard-coded Korean `aria-label="메뉴 닫기"`
  are localized; `closeMenu` was added to both copy sets.
- Bumped the application and package display version to `3.0.0-beta.14`.

## Automated verification

- `npm test`: 152 tests passed, unchanged from Beta 13. This release touches presentation, so it
  adds no unit tests.
- `npx tsc --noEmit`: passed.
- `npm run build`: passed TypeScript checking and the Next.js 16.3.3 production build.
- `scripts/test-beta14-integration.mjs`, added by this release, passed at 1180×900 and again at
  420×820. It asserts against the served stylesheet that no literal pixel corner survives; that
  `--dim` resolves to the raised value and clears 4.5:1 against all eight surfaces, computed with
  the WCAG luminance formula rather than asserted; that the document language follows a change from
  Korean to English and back; that an icon-only action answers hover with colour and weight and no
  plate; that a focused control shows an outline ring and a focused field the shadow ring; that a
  search dialog opens with the keyboard in the field it named; that the model title truncates and
  ends before the surface actions begin at both widths; and that no native browser dialog and no
  page error occurred at any point. It was run three times consecutively to confirm the hover and
  focus assertions settle rather than race.
- `scripts/test-beta11-integration.mjs` caught a real regression during this work: the first pass
  of the corner ladder collapsed the 22px card step into 20px, dropping the storage file cards
  below the `>= 22` floor that test encodes for MASTER.md's "shared large corner language". The
  ladder gained `--radius-card` in response and the suite passes.
- `scripts/test-beta3-ui-integration.mjs`, `test-beta10-integration.mjs`,
  `test-beta11-integration.mjs`, `test-beta12-integration.mjs`, `test-beta13-integration.mjs`,
  `test-harness-integration.mjs` and `test-compaction-integration.mjs` all pass.

## Pre-existing failures, unchanged and out of scope

Each was reproduced against the unmodified Beta 13 tree or traced to the release that changed the
behaviour under test. None is caused by this release, and repairing another release's QA is not
this branch's work.

- `scripts/test-beta8-integration.mjs` waits for `.assistant-edit textarea`. Beta 13 moved answer
  editing into the shared modal and removed that inline editor; `assistant-edit` occurs once in
  `app/page.tsx` at Beta 12 and zero times at Beta 13.
- `scripts/test-beta9-integration.mjs` enters multi-selection by long-pressing a file preview.
  Beta 10 replaced long-press with the explicit `.storage-batch-button` action; no pointer-hold
  handler remains in `app/storage-manager.tsx`.
- `scripts/test-audit-integration.mjs` fails at its preset-preservation assertion (line 80), the
  same failure Beta 13's audit recorded as pre-existing.
