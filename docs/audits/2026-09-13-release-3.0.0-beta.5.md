# 3.0.0-beta.5 validation

## Search, pagination, and audit authorization

- Personal storage and administrator file audit use debounced filename search, server pagination, and ascending/descending sorting by filename, original size, or creation time.
- Administrator conversation audit is capped at 10 rows per page. Search covers titles, full or partial conversation IDs, and message text in every branch.
- Audit is an explicit administrator capability granted only by Superadmin. Administrators without the grant receive HTTP 403 for another user's conversation and file audit endpoints and cannot grant the capability to themselves.
- Growing conversation and file collections remain in separate full-size audit dialogs. Conversation review opens in place and retains every branch; file audit provides grid/list modes and individual/all-file downloads.

## Retention and storage accounting

- User deletion of conversations and files is soft deletion. Normal list, read, search, and attachment routes hide deleted resources, while auditors can filter deleted records, restore them, or permanently remove them.
- Deleted conversations and unreferenced files are purged after the configurable 1–60 day retention period. A process-wide maintenance scheduler runs in addition to request-time cleanup.
- Every user has a separate trash quota, initialized to twice the active storage quota. When it is exceeded, eligible deleted files are removed oldest-first; restore is rejected if the active quota cannot accommodate the file.
- User storage never exposes trash enumeration or deleted file access. Administrator totals count active plus trash allocations and usage while keeping separate thin active/trash percentage meters and detailed hover/focus tooltips.

## UI refinements

- The user-management overview has consistent spacing between aggregate/default-quota cards and account creation. Storage quota values and unit selectors share aligned label rows.
- Superadmin sees a narrower role selector with a neighboring Audit toggle when managing an administrator.
- Chat Markdown images and image attachments open a near-viewport lightbox. A fixed top-right X, Escape, or backdrop click returns to the chat.
