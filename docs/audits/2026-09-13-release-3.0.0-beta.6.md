# 3.0.0-beta.6 validation

## Storage defaults and user management

- Harness settings now own the active-storage default, trash default, and 1–60 day deletion-retention period. A per-user value of zero records inheritance rather than a literal zero-byte quota; inherited accounts follow later workspace-default changes in one database transaction.
- New and first-run accounts inherit both defaults. Reducing a default below an inherited user's current usage is rejected before the configuration is written.
- User management opens in a separate modal with debounced username, display-name, and ID search plus a fixed 10-user server page. Rows and aggregate totals report active storage and trash independently.
- Administrator conversation and file-audit search fields use the same input geometry and visual tokens as the rest of the settings UI.

## Storage attachments and model access

- The composer can select existing image/PDF files from the signed-in user's storage through the existing filename search, sort, and pagination browser. A draft reference never deletes the underlying retained file.
- Image/PDF uploads selected from the host are retained in private storage by default. Owner checks remain on every storage and upload read; another user receives HTTP 404.
- The new `storage_access` tool searches only the current user's active files. It can return safe bounded text or attach an owned image/PDF as model input; ambiguous names require a file ID or more specific query.
- `host_computer.store_file` uses the same private-storage path and immediately feeds imported images/PDFs into a multimodal follow-up turn.

## Tool menu and limits

- Composer tools are grouped into collapsible Internet, Ambient awareness, Agent, and Interaction sections. The popover has a viewport-aware maximum height and scrolls internally, including in the vertically centered idle layout.
- Maximum tool-call rounds validate and render through 10,000. Runtime tool calls are still intentionally serial, so no misleading parallel-call-limit control is shown.
