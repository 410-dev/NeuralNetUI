# 2.1.3 validation

## Changes

Pre-send historical compaction and live output threshold detection (including reasoning and tool argument deltas). Request-local cancellation, bounded summary fragments, literal resume templates and a configurable per-response resume cap. Desktop prompt actions share one row; mobile stacks them. Settings have backward-compatible defaults; no migration.

## Verified

- 106 unit tests passed, including literal/non-recursive substitution and exact threshold boundaries. The new test failed before implementation.
- TypeScript `npx tsc --noEmit`, production `npm run build`, script syntax check and `git diff --check` passed. No standalone lint command is configured.
- Isolated database/mock HTTP integration: pre-send summary precedes inference, content and reasoning stop/resume, original prompt substitution is literal, upstream disconnection, resume-limit error, summary failure without replay, zero-resume cap without a summary request. Incomplete tool arguments never execute; all summary requests fit the mock model context budget. All seven scenarios passed.

## Limits

No interactive browser or real LM Studio inference QA in this release. The native request receives the same combined abort signal; native cancellation was inspected in source. Token counts remain estimates until upstream usage is available. MSI installation and service restart are not performed.
