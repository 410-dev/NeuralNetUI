# 3.0.0-beta.4 validation

## Private host-file storage

- The Superadmin-only host-computer tool now exposes `store_file` as a separate risk-3 permission. Requests to attach, upload, show, or share a host file default to this owner-only storage operation; `upload_temp` remains a distinct external action used only when the request explicitly names `temp.hysong.dev` or asks for a temporary external link.
- Host files are copied into the current user's quota-backed storage without modifying the source. The tool returns the owned attachment plus exact Markdown for an inline raster image or a forced-download link for a general file.
- Upload migration 12 permits bounded MIME metadata for general files. MIME detection recognizes safe raster signatures and PDFs; invalid image content is downgraded to a generic download. Unsafe/general content never renders inline.
- Large host images receive bounded JPEG thumbnails through Sharp. Original files remain intact, and authenticated original/thumbnail responses use `private, no-store`, `Vary: Cookie`, owner checks, and `nosniff`.
- Integration verified that the owning account can load its original and thumbnail, another authenticated account receives HTTP 404 for the same upload ID, and the administrator audit thumbnail is a JPEG.

## Administrator audit browsers

- The account/role/quota editor no longer contains growing record lists. It launches independent full-size chat-record and file-storage dialogs.
- Conversations use server-side pagination (20 per page). An administrator can export an individual/all conversations or open one in an in-place web review, switch among every branch, and inspect messages, reasoning, tool activity, and owned attachments.
- The web review rewrites normal owner-only upload URLs through the target-user audit endpoint rather than weakening the primary upload route. Every list, review, and export action remains audit-logged; ordinary users receive HTTP 403.
- Files use server-side pagination (24 per page) and SQL-backed ascending/descending sorting by filename, original size, or creation time. Both thumbnail and list layouts show name, MIME type, size, and creation time, with individual download and all-files ZIP export.
