# NeuralNetUI 3.0.0-rc4-b24 audit

## Scope

- MCP authentication badge styling
- Syntax colouring for chat code snippets and artifact Code mode
- Shared enter and exit motion for independent modals
- Settings-sized artifact viewer with maximize and restore controls

## Implementation notes

- `lib/syntax-highlighting.ts` registers a bounded set of common languages with highlight.js core. Explicit unknown languages fall back to escaped plain text; unlabeled snippets use automatic detection across only the registered set.
- `lib/use-modal-focus.ts` provides presence-delayed closing for migrated dialogs and a short non-interactive exit snapshot for existing modal callers, preserving one close motion throughout the application without changing their business logic.
- The artifact iframe remains sandboxed. Syntax highlighting renders only highlight.js output, which escapes source text before token markup is inserted.
- Artifact windows start at the settings-panel dimensions and transition to a borderless viewport surface only after the explicit maximize action.
