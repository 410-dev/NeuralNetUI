# 3.0.0-beta.10 validation

## Storage and related chats

- The personal storage manager and attachment picker use two columns. The client derives a 3–7 row page size from viewport height and width, and the modal retains an outer viewport margin instead of becoming full height.
- An explicit Select multiple action enters bulk mode. The download/delete column becomes one vertically centred circular check control; the attachment picker uses the same control instead of text Select/Deselect buttons.
- Referenced files keep an enabled delete action. It opens a related-chat dialog with chat navigation, circular multi-selection, selected soft deletion, and an atomic transaction that soft-deletes every currently referencing chat with the file.
- Server reference counts now count distinct active conversations. Already deleted chats do not indefinitely block an active file, while ownership, existence, complete-reference selection, and batch limits are validated inside SQLite transactions.

## Chat management and model settings

- A small indented Manage chats action sits at the bottom of the sidebar history scroller. Its modal searches titles, IDs, and message content; filters by hours or days since last activity; selects the current page or individual chats across pages; and soft-deletes selected or all filter-matching chats.
- Search and Storage manager sidebar controls now use the same 8px separation as New Chat and Search.
- Vision is localized as Image input and no longer sits in a nested settings group. The fixed long-edge input is immediately left of the switch and is disabled while original-image mode is active.
- Runtime inspection confirmed that the selected alias object is passed to attachment, storage-tool, host-import, and screenshot image preprocessing. `inheritReasoning` preserves the alias `visionImageMode` and `visionMaxEdgePixels` while inheriting only reasoning capabilities; the unit regression now asserts that behavior.
